# 台表科 (6278) | 公司訪談

> 公司：[[6278 台表科 (TSMT)]]

## Q2 2026 財務結果 — 營收符合，毛利低於指引，費用略高

- **Q2 營收 QoQ +5.38%**：符合公司預估；成長動能來自三塊：
  - TFLCD 面板相關（台灣 / 大陸 TV 面板、日韓 Monitor TCon 板、Mini LED TV）
  - WiFi Module 與手錶 FATP 組裝
  - DRAM 模組少量成長

- **Apple 產品拖累 Q2、反彈集中 7 月**：MacBook Cable / TCon 板因 IC、PCB 缺料，Q2 出貨低於預期；料件六月底才到齊，7 月集中生產出貨，月營收因此明顯衝高。

- **Q2 毛利率 11.79%**（vs Q1 11.3%；低於指引 12-12.5%）：
  - 產品組合：Q2 以 TFLCD 出貨為主，毛利相對較低
  - 庫存成本時間差：預購高成本原料計入 Q2，但新定價從 Q3 才啟用

- **Q2 OPEX NT$7.4 億**（vs 指引 7-7.2 億）：
  - 美國辦公室人員持續增加（AI、衛星業務拓展）
  - 海外技術 / 業務人員出差成本增加

- **Q2 業外收益 ~NT$8,700 萬**：台幣貶值帶來匯兌正效益，但部分被印度盧比（Rupee）貶值抵消

- **Q2 綜合財務數字**：
  - 稅負較低（海外盈餘分配回台，預提扣繳稅回沖）
  - 稅後淨利 ~NT$8 億；EPS NT$2.73
  - H1 稀釋 EPS（含庫藏股）：約 **NT$4.8**（YoY 成長；2025 H1 因台幣急升匯損較高）

## Q3 2026 指引 + H2 毛利展望 — 毛利率明顯回升至 14%

- **Q3 營收 QoQ +5%**：Apple Cable / TCon 補回（料件到位）+ DRAM 模組持續成長；出貨量 QoQ 估增約 **10%**，但因 Buy-and-Sell 比重上升，營收成長幅度（5%）低於出貨量增幅。

- **Q3 毛利率目標 ~14%**：管理層表示「以目前看應該沒有太大問題」。
  - 驅動因子：Apple 產品回升（較高毛利）；DRAM 模組部分轉 Buy-and-Sell（毛利 20%+）；新定價 Q3 正式啟用
  - H2 方向：14% → 15%（Optical 純代工毛利 20%+；AI server 代工有機會達 30%）

- **H2 OPEX 每季約 NT$8 億**（vs Q2 7.4 億）：美國人力持續增加 + 獲利提升帶動員工分紅增加

- **Q3 折舊 ~NT$5 億**；Q4 因合肥新線驗收折舊略增，但對毛利率衝擊有限

## 光通訊（Optical）組裝業務 — Q4 起量，2027 年增新客戶

- **業務模式：純代工（Free Chip）**：客戶掌控所有料件（含晶片），供應商直送台表科廠；加工報價直接即毛利來源。
  - 料件控制預計明年才有機會重新討論帶料模式；現以保障出貨為優先

- **產能進度**：
  - 8 月底：現有產線幾乎全數 Ready
  - 10 月：再開出一條線
  - Q4：視情況再加一條（已含入原始 $1.5 億資本支出計畫）

- **出貨時程與業績貢獻**：
  - Q3 2026：少量爬坡
  - Q4 2026：佔單季營收約 **4-5%**
  - FY2027（現有客戶）：佔全年 **5-10%**
  - FY2027（新客戶加入後）：比重可能再往上修

- **新客戶 2027 年量產**：將在**東南亞廠區**生產（非中國，規避中美議題風險）

- **競爭者對標**：同業在大陸 + 馬來西亞（馬來 ~3-4 條線）；馬來端一條線每年純代工營收可達 **NT$12-13 億，毛利率 30%+**；管理層確認台表科毛利潛力相當（「基本上是可以的」）
  - 同業前段製程（光對準 / hub 接合）部分不同；台表科目前確認配置尚需內部確認

- **料況仍是唯一瓶頸**：產能已 Ready，PCB / MLCC 料況緊繃，「料到即生產」

## DRAM 模組 — 陸系 IPO 大客戶加速，美系 1.6T 試產中

- **陸系主力客戶（IPO 籌備中）**：6 月起量明顯往上走；2027 H1 量較 2026 增加 **20-30%**。
  - Q4 2026：在合肥增加 **4 條 SMT 線**以應對 2027 需求
  - 毛利模式：DRAM 顆粒為 Consign（客供）；PCB / PMIC 原為台表科帶料（毛利 15-18%）；受料況混亂影響部分改為 Buy-and-Sell → 毛利提升至 **20%+**，部分時點可達接近 **25%**
  - 延伸群聚效應：合肥廠已通過大陸 CSP 認證，吸引其他陸資中小客戶委託 DRAM / SSD 模組代工，整體陸系量逐步積累

- **美系客戶**：
  - 80G：目前**量產**中
  - 1.6T：目前 **Try Run** 中；快則 Q4 正式量產，主要放量在 2027
  - 1.6T ASP 優於 80G（客製化程度高、工序複雜）；1.6T 毛利亦更好
  - 1.6T Solution 目前客戶仍有多種方案選擇，最終歸納幾個後台表科配合生產

## Tesla / SpaceX / xAI / AI Server — 下半年量升，2027 機器人大量

- **Tesla 汽車（門把 / Display / Camera Module）**：
  - 含料代工（帶料 + 組裝）
  - 9 月起至年底持續加量；下半年優於上半年
  - 2027 年仍維持成長動能

- **Tesla Datacenter（AI 訓練板）**：本來就有供應；料件因交期長已提前備料，H2 8-9 月料件陸續到位即生產；純代工模式。

- **Tesla Optimus 機器人（Camera Module）**：
  - 目前正在談 2027 年大量生產的訂單規模
  - 2027 年量將**明顯**反映在營收，為 Tesla 業務新增長點

- **SpaceX**：Q3 末 / Q4 初 Try Run；貢獻在 **2027 年**；將在墨西哥廠生產（客戶要求配合）

- **xAI（原文 "SAI"，待確認）**：已在試產中；與 Tesla datacenter 板分開計算

- **AI Server（非 Tesla / SpaceX）**：純代工；H2 Q3-Q4 逐步增加幾個客戶；
  - 目前 AI 相關（排除 Optical）佔營收約 **2%**
  - 2027 年預估達 **5%+**（管理層確定），Q4 客戶落地順利則有上修空間

- **BBU（原文 "BPU"）**：Q4 以 Try Run 為主，佔營收不多；正式貢獻在 **2027 年**

## 產能與資本支出擴充計畫

- **FY2026 資本支出：~$1.6 億美元**（vs 原計畫 $1.5 億，增加 $1,000 萬）
  - 增加主因：合肥 **+4 條 SMT 線**（DRAM 陸系客戶 2027 需求）
  - 原計畫內：Optical 光通訊線（8 月底 + 10 月）；**墨西哥 +1 條線**（Q4）
  - 合計新增設備：5 條線（4 條合肥 DRAM + 1 條墨西哥 Optical）

- **設備交期 ~1 季**：設備廠本身亦缺料，交期有延長壓力；確認訂單後 → 到廠 Try Run 約 1 個月

- **印度廠（清奈）**：原做 5G 模組（現需求放緩）；Q3/Q4 起增加**韓系品牌 TV / 空調板子**（韓系廠商退出中國後轉移至印度製造）；北部新廠啟用後將量產 DRAM 模組

- **產線共用性高**：Optical / AI server / DRAM 模組設備大多可彈性調配；僅少數特殊規格（如 server 板重量 / 尺寸）需額外購置設備

## PQ 拆解

### TFLCD Display（TCon / Lightbar / Touch）｜H1 48%
- **Q（量）**：Q2 為主力出貨；H2 因 TV 市場偏弱略降，韓系 Monitor TCon + Apple TCon 支撐
- **P（價）**：帶料毛利相對較低；為 Q2 毛利低於指引的主要 mix 因素

### Cable｜H1 5%（vs FY2025 9%）
- **Q（量）**：H1 因 IC 缺料明顯偏低；H2 料件陸續到位，出貨量明顯回升

### DRAM 模組｜H1 16%，H2 16-20%
- **Q（量）**：陸系大客戶 6 月起持續上量；美系 80G 量產中；整體 H2 QoQ 持續提升；1.6T Try Run，2027 放量
- **P（價）**：轉 Buy-and-Sell 後毛利 20%+（vs 帶料時 15-18%），部分時點接近 25%；1.6T ASP 及毛利優於 80G

### Optical 光通訊｜Q4 單季 4-5%，FY2027 5-10%
- **Q（量）**：Q3 少量爬坡；Q4 佔單季 4-5%；FY2027 佔全年 5-10%（現有客戶）+ 新客戶加入
- **P（價）**：純代工，加工費直接即毛利；潛在毛利率 ~30%（對標同業）

### Automotive（Tesla 汽車 + Camera Module）｜H1 8%
- **Q（量）**：9 月起顯著加量；Optimus 機器人 Camera Module 談 2027 大量訂單
- **P（價）**：含料代工；Tesla 產品 ASP 較好，整體 H2 毛利貢獻優於 H1

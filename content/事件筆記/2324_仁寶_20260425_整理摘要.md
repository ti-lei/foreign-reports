## Q1 2026 營收表現與結構

- **Q1 整體營收**：QoQ 約持平微增（+1%），PC 量跌但 ASP 升幾乎完全抵銷。
  - PC 出貨量因 Streemont 平台下滑約 19%
    - Memory 漲價推升 ASP 約 +10%，幾乎完全抵銷量的衰退
  - Smart Device 因季節性因素略為下滑，屬正常現象

- **最大驅動力來自 Server**：Q1 占營收已達約 5%，2025 全年僅約 1–2%。
  - 單季 Server 營收幾乎接近 2025 全年 Server 總營收
  - 全年目標營收 64B（年初 guidance），方向不變

---

## Server 業務詳情：B300 平台爆發、客戶組成

- **Server 內部結構**：AI server 約占 70%，General Purpose 約 30%，ASP 差距懸殊。
  - GP：ASP 約 1,000–2,000 美元，毛利低
  - AI server（B300）：一台約 20–30 萬美元，GPU pass-through 比重高

- **B300 平台是 Q1 最大收入來源**：2025 年 11 月完成認證，Q1 開始放量出貨。
  - Vera CPU 與 Ruby HGX 已分別取得認證，但 Vera Ruby 整合平台尚未 qualify
  - AMD 平台（現為 MI 450）：客戶需求低，2025 全年幾乎零出貨

- **客戶組成分三類**：Regional（現階段主力）→ Enterprise（基本盤）→ CSP（新里程碑）。
  - Regional（歐洲、東南亞白牌）：目前主力，B300 出 L10 整機
  - Enterprise（中大型企業）：原做 L6 general server，持續出貨，為既有基本盤
  - CSP（四大雲端）：**已拿到其中一家 CSP 的 L6 訂單（里程碑）**，今年內出貨；另一家仍在洽談中

- **Business Model**：GPU 由客戶指定後仁寶協助採購直接出貨，庫存停留時間短，接近 PC 代工模式。
  - Consign/囤貨行為極少

## 北美廠進展與產能布局

- **北美廠（德州）**：原目標 Q2 底 ready，不確定性高，建議 Q2 底再追蹤。
  - 主要不確定因素：供應鏈、yield rate、人力成本，廠區仍在建置中
    - 定位：出貨給美國客戶（含未來 CSP 訂單），避開關稅；非美客戶繼續由亞洲供應

- **現有補位產能**：越南廠 + 台灣廠，B300 L10 出貨主要從越南打板、台灣組裝。
  - 越南廠已在擴增 SMT，年初九成已就位

- **全年資本支出 18B**：較 2025 年 8.2B 增加約 10B，主要用於北美廠 + 越南廠 + 台灣廠擴產。

- **AI 研發人力短板**：RD 人員目前約 700–800 人，競爭對手（廣達等）已達 2,000–3,000 人以上。
  - 原目標年底 1,000 人，未達標

## PC 業務：市場份額、ASP 與 Q2 展望

- **客戶組成**：Dell 最大（約 5–6 成），Lenovo 與 HP 各約 6%，三者合計超過 7 成。
  - 產品 Mix：Commercial 約 4 成多，Gaming 約高個位數%，其餘為 Consumer
    - 對低階競爭（如華擎 ASP ~200 美元）：不直接競爭，繼續走中高階路線

- **2025 年 PC 營收下滑約 4B**：Dell 表現不佳 + Lenovo 搶走市占。
  - Dell 自身 2025 年表現不佳，拖累仁寶訂單
  - Lenovo：In-house 產能占其 6 成，中國 EMS 約 2 層，台灣供應商（含仁寶）從 3–4 層縮減至約 1 層

- **Q2 PC 展望樂觀**：Dell 今年表現較好，Q2 訂單預計回流，量價雙升。
  - Q1 ASP 達約 750 美元（QoQ +~100 美元），主因 memory 漲價
    - AIPC 定義機型 ASP 約 900 美元
  - 公司內部看到每月 ASP 約 +2.5% QoQ

## Margin 展望與下半年壓力

- **Server 毛利率**：L6 GP 約幾個%，L10 AI server 整機約 5–6%，整體高於 PC corporate margin。
  - GPU 占 B300 BOM cost 約 7–8 成，pass-through 拉高 revenue 但壓縮 margin rate
    - Regional 客戶因 project 性質，毛利略有彈性

- **下半年 margin 壓力**：Memory/CPU 漲價 + 整機比重提升後 pass-through 效應更大。
  - Memory 從 Q4 開始每季漲約 10%；CPU 部分廠商策略性調漲；被動元件也有漲價預期

- **OP Margin 展望**：2025 年約 1%+，2026 年下半年壓力較大但不會快速惡化。
  - 費用預計低個位數成長，Server 量若真正放大，費用可能超出此範圍
    - 公司現金流充裕，財務狀況與同業相比穩健

## AIPC 趨勢與 ARM 陣營觀察

- **AIPC 滲透率小幅提升**：2025 年約 32% → 2026 年約 35%，成長低於市場預期，但內部結構改變明顯。
  - NPU >40 TOPS 機型占比從 10% 升至 21%，高效能 AIPC 需求逐漸成形

- **ARM 陣營持續擴大**：Qualcomm 穩定，MTK 在中階市場從幾近零升至約 5% 市占。
  - NVIDIA 今年加入 ARM PC（N1X），可能進一步強化 ARM 陣營
  - x86 陣營中 Intel 表現不如預期，部分規格問題導致推廣受阻

- **漲價敏感度分化**：高階 PC（1,000 美元+）消費者敏感度低；低階白牌（200 美元）受衝擊最大。
  - 推估為 Aggers 類廠商掉量主因

## ASIC 業務立場

- **ASIC 立場保守**：設計主導權在 CSP 端，ODM 角色類似 EMS 代工，毛利偏低。
  - RD 資源投入 ASIC 的 CP 值不如專注 GPU server 整機業務
    - 若特定客戶有客製化需求不排除評估，但目前非策略重點

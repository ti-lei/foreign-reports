## 報告總結

本報告為 MS 對大中華硬體 OEM 8 月 2Q 財報季的前瞻，核心結論是三家（Lenovo、技嘉、華碩）獲利都將優於市場共識，且驅動力一致：**AI server 組合改善＋營運槓桿帶動的營益率上行**，而非單純營收超預期。MS 對 Lenovo 2Q 調整後淨利估高於共識 12%、技嘉 EPS 高 15%、華碩 EPS 高 34%，三者都判斷「營益率」為關鍵 KPI 且偏向上檔驚喜。

MS 近期上調 Lenovo（「從記憶體逆風轉為結構性順風」），看好其 ISG（伺服器）業務；並在「AI + Chipflation」框架下認為記憶體漲價可由 OEM 定價轉嫁消化。本報告 3 張圖皆為各公司 MS 估計 vs 共識的比較表（依裁圖規則屬跳過類），故本筆記為純文字前瞻。

## 重點細節

**Lenovo（0992.HK）**：F2027e 開局強，1Q27 調整後淨利 US\$788mn（+102% YoY／+41% QoQ），高於共識 12%，主要靠利潤率而非營收；營收 US\$24bn（高於共識 7%）；GM 估 16.6%（+190bp YoY，反映持續調價＋在高記憶體價下轉嫁零件成本能力）。惟預期認列與 warrant 衍生金融負債相關的大額非現金評價損失，HKFRS 帳面可能轉虧——MS 建議看調整後（非現金項目調整）淨利 US\$788mn。

**技嘉（2376.TW）**：2Q26 預估優於市場，AI server 需求強＋主機板與顯卡出貨佳；初步營收 ~NT\$144.2bn（+37% QoQ／+41% YoY，beat 共識 13%）；營益率估 6.1%（vs 街估 5.5%，+60bp），營運槓桿帶動。

**華碩（2357.TW）**：2Q AI server 組合更強＋行銷費用減，帶動營益率估 5.9%（vs 街估 4.6%，+120bp）；EPS 估高於街估 34%。

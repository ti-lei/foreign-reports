# Goldman Sachs｜全球光收發器：上修 1.6T+ 出貨 29%/61%/50%（2026-28E）；速率升級持續

**券商**：Goldman Sachs  
**分析師**：Allen Chang、James Schneider、Ryo Harada、Daiki Takayama、Anmol Makkar、Ting Song、Yifan Hu、Hiroki Muramatsu  
**日期**：2026-09-07  
**主題**：全球光收發器出貨量大幅上修；1.6T 爬坡 + 3.2T 啟動 + SiPh 滲透率提升三重驅動；Buy：Eoptolink、FOCI、Landmark、VPEC、RoboTechnik

## 報告總結

GS 大幅上修全球光收發器 TAM，從舊估的 US\$50.9bn/72.6bn/69.1bn（2026-28E）提升至 US\$67.7bn/131.4bn/148.5bn（+33%/+81%/+115%），主要驅動來自：（1）AI 機架式伺服器出貨量遠超預期（2026E +190% YoY）；（2）每 GPU 晶片光模組使用量提升；（3）ASIC AI 伺服器採用 800G+ 連接滲透率加速。本次是 GS 自 2025 年以來的第五次上修，每次修幅均達 20%+ 以上。

SiPh（矽光子）將在高速段主導：GS 預期 800G/1.6T/3.2T 的 SiPh 滲透率分別達 60%/80%/80%。CPO 在 800G+ 中的滲透率預期從 2026E 1% 爬升至 2028E 9%，CAGR 105%。Buy-rated 供應鏈：光收發器及引擎製造商（Eoptolink、FOCI）、CW 雷射/磊晶片供應商（Landmark、VPEC）、設備（RoboTechnik）。

## AI 收發器速率採用框架

GS 的核心觀察：
- **GB200 NVL72**：GPU layer 使用 400G，leaf/spine/core layer 使用 800G
- **GB300**（2H26 開始）：GPU layer 使用 800G，leaf/spine layer 使用 1.6T
- **Rubin / Rubin Ultra**（2H27+ 預期）：進一步遷移至 1.6T 和 3.2T
- **ASIC 伺服器**（Google、Meta）：ASIC 採用 800G+ 的 Google 是最早的 CSP 之一遷移至 1.6T；Meta 每個 ASIC 使用更多光模組（vs GPU server 通常 2-3 個）

SiPh 在高速段的成本優勢：
- 1.6T SiPh 光收發器：使用四個 70mW CW 雷射，雷射成本 US\$15-20/模組
- 1.6T EML 光收發器：使用八個 200G EML，雷射成本 US\$160/模組
- 成本差異推動 SiPh 在 1.6T 佔比達 80% from 2026E

# 日月光投控 (3711) | 公司訪談

> 公司：[[3711 日月光投控 (ASEH)]]

## FullProcess（CoW）大客戶 9 月量產 — 2026 全年 US$3 億，2027 大幅擴量

- **FullProcess 2026 年全年 ~US$3 億（US$300M）**：來源分散，9 月前（1-8 月）已在收，客戶涵蓋 ASIC 廠、Design Service 公司、舊款 Hopper GPU 餘量。
  - 各小客戶每家貢獻相對小，管理層未具名
  - 9 月新大客戶 ramp：月 run rate ~US$5,000 萬（Q4 合計貢獻約 US$2 億，4 個月）；大客戶起步晚，2026 年占全年 US$3 億比例反而「相對低」

- **ASEH 現況為獨家供應商，但仍無法滿足客戶全部需求**：大客戶持續上調需求，ASEH 產能追不上，未來客戶勢必尋找第二來源（2nd source）。
  - 目前仍是客戶首選（技術成熟度最高、台灣在地、Pure Play 定位）
    - 大客戶部分機台屬客製規格（客戶自行 consign），共用性低故由客戶承擔

- **2027 年：大客戶主導 FullProcess；其他客戶明顯貢獻要到 2028 年**：
  - 明年大客戶佔據 FullProcess 大部分產能；其他 CPU 類客戶工程量先行，量產等產能
  - 產能爬坡節奏：Q4 2026 → Q1 2027 緩坡，Q2 或 Q3 2027 才更明顯加速（機台交期決定）

- **GPU 比 CPU 複雜，暫不導入**：大客戶 GPU Die 更大、Layer 更多、需埋更多 Bridge，良率挑戰更高；目前先專注 CPU，光 CPU 需求就已做不完。

## Leap 定義重塑與總規模 — 2026 US$3.7B，2027 目標 US$7.5B

- **Leap = CoWoS-related 先進封裝，舊「先進」定義已調整**：原 ASEH「先進封裝」定義涵蓋普通 FlipChip Bumping（FCBGA）；現在將 CoWoS-related 服務獨立拆出命名為 Leap；TSMC 對「先進封裝」的定義不同，故 ASEH 特別區分。
  - 「先進封裝」50% 占 ATM 收入拆解：Leap（CoWoS-related）~20%、一般 FlipChip Bumping / FCBGA / WLCSP / FCCSP ~30%
  - 一般 FlipChip Bumping 不算在 Leap 裡；CoWoS-related 才算 Leap

- **2026 年 Leap 總規模約 US$3.7B；2027 年目標約 US$7.5B（幾乎翻倍）**：
  - Leap 收入拆分：75% 封裝（US$2.8B）、25% 測試（US$0.9B）
  - 測試內：~75% 是 ChipProbing（US$0.675B）、~25% 是 FinalTest（US$0.225B）
    - ChipProbing 單位面積毛利高於 FinalTest，工廠空間優先分配給 ChipProbing

- **FullProcess 是 Leap 的子集，今年 US$3 億，成長率最快但絕對金額仍小**：
  - FullProcess = CoW 製程完整封裝服務（含 Organic Substrate 層），Capital Intensity 介於 OS（最低）與 Testing（最高）之間
  - 明年 FullProcess 成長率最高，但 Leap 絕對金額貢獻最大仍是 ChipProbing 等業務

- **美國無先進封裝產能，Leap 業務 100% 集中台灣**：美國只有小型測試服務場（非量產），人力與成本為主因；現階段集中資源擴大台灣是管理層明確策略。

## 產能擴張策略 — 集中台灣，今年買廠 8 座，COW 機台交期 12 個月

- **今年在台灣公告已購入 8 座既有廠房**：自建廠 2028 年才開出，買廠是取得 2027 年所需空間的唯一途徑。
  - 未能及時買廠，2027-2028 年客戶需求將無法滿足

- **兩大產能瓶頸：空間 + 機台交期**：
  - 空間：買廠補空間，需求持續就繼續買
  - COW 製程機台交期最長，達 12 個月或以上；設備供應商同樣低估需求，台積電優先拿到同款設備
    - ASEH 與 TSMC 競爭同一批 COW 機台，TSMC 規模更大必定先拿

- **產能規格對齊 TSMC 標準**：ASEH 尺寸規格與 TSMC 相同，使設備供應商有更高動機投資支援（服務兩家而非一家）。

- **明年 Q2 / Q3 才出現更明顯的產能爬坡**：管理層以現有空間與機台交期推算，無法給出精確產能數字，也沒有可揭露的 checkpoint。

- **機台共用性原則**：共用性高 → ASEH 自購；共用性低（客戶特製 CPU 機台）→ 客戶 consign，ASEH 不承擔閒置風險。

## 毛利率展望 — ATM Q4 2026 突破 30%，Leap ≥30%，測試滿載 30-40%

- **ATM 結構性毛利率指引「24-30%」已需修正**：Q4 2026 ATM 毛利率預期突破 30%，管理層表示明年年初須重新給指引範圍。
  - 主因：Leap 高毛利占比持續提升；同時 Mainstream（非 Leap）毛利率因產品升級與價格調整也在改善

- **Leap / FullProcess 毛利率 ≥30%**：具體不揭露，表示在 30-60% 的寬範圍中；明確高於 ATM 平均，低於 TSMC 先進製程。
  - FullProcess Capital Intensity 排序：Testing（最高）> FullProcess > OS（最低）
  - FullProcess 包含 OS 作為整合服務一部分，OS 是 Capital Intensity 最低者，故 FullProcess 介中間

- **FinalTest 毛利率：滿載時 30-40%**：毛利率滿載時良好，但 System Level Testing 若捆綁，空間占用大、每平方公尺收益低，工廠傾向不優先配置。

- **Mainstream（一般封裝，非 Leap）毛利率亦同步改善**：材料成本（如載板）上漲，透過與客戶談漲價反映；非趁火打劫，維持長期合作關係。

- **折舊趨勢**：2026 年絕對金額大幅增加（重 CapEx 年）；占營收比重略微下降（因為營收成長幅度高於折舊成長）；2027 年難估，取決於營收實際成長速度。

## NVIDIA GPU FinalTest — 2026 象徵性份額，2027 空間配置待定

- **2026 年 NVIDIA AI GPU FinalTest 份額「象徵性」**：空間優先給 ChipProbing（毛利率更高、每平方公尺效益更好、換線少、自動化更容易）。
  - System Level Testing 占空間大、每平方公尺產出低，工廠最不傾向做

- **2027 年份額**：尚未決定，取決於可分配給 FinalTest 的空間多寡；管理層稱空間配置方案仍未定案。

- **Burn-in 設備選擇**：NVIDIA GPU 使用 Advantest 機台（高瓦數，可支援 GPU 高功耗）；市場有多家第三方方案：MCC、Advantest（TEDX 系列）、AEM 等。
  - 傳統靠自製 Burn-in 機台的封測競爭者面臨再投資壓力（舊機台無法應付高瓦數 / 水冷需求）
  - ASEH 傾向第三方方案：客戶可 multi-source，ASEH 彈性更大（不被單一機台規格綁死）

## EMIB（Intel 技術）— 持保留態度，不視為主流威脅

- **技術挑戰：載板精密度是關鍵瓶頸**：EMIB = 把 Silicon Bridge 塞進載板；載板廠製造精密度遠低於做 RDL 或 Organic Interposer 的先進封裝廠。
  - Silicon 與 Substrate CTE 差距大，熱應力難控制，良率難維持
  - Intel 公布的良率（如 ~90%）是 Wafer 端；管理層認為載板端良率仍低，外界低估了這一關

- **商業模式可持續性存疑**：目前 Intel 補貼載板廠推進此技術；若 Intel 停止補貼，載板廠未必願意繼續投資，技術路線可能停滯。

- **ASEH 可參與，但不主推**：若客戶自帶良好載板，ASEH 可做後續組裝（不被排除在外）；ASEH 自身提供 RDL-based 替代方案，或客戶可採 2.5D + 3D 組合設計（如 AMD MI 系列模式）。

- **EMIB 難成主流的結構原因**：若只有 Intel 提供此技術，客戶不敢全力押注（單一供應商風險）；客戶都需要多供應來源選擇。

## EMS 業務 — 超預期，Apple 穿戴 SIP + AI Server PCBA 驅動

- **EMS 2026 年高於年初預期**：部分原因是 Memory 等零件漲價拉高代料金額（代工廠代料，料價漲 → EMS 名義營收同步拉高），非全部來自訂單結構改善。
  - 美國手機品牌（Apple iPhone）：穩定，無明顯大幅成長或下滑

- **成長驅動：Apple 穿戴 SIP + 美國 AI Server PCBA**：
  - 新 SIP 產品供 Apple 穿戴式裝置，今年成長最明顯
  - 美國 AI Server 公司 PCBA 主板組裝（成長動能之一）
    - 僅做 PCBA 主板組裝，不含整機 / 機架；再往下游裝配由客戶完成

- **EMS AI / Computing 業務規模**：AI 相關帳號 ~10 個；整個 Computing 類帳號 ~20 個（含 AI + 一般伺服器）；AI 基礎建設相關帳號去年已有一批確認。

- **Automotive + Networking 回溫**：前兩三年去化不足，現在約回到 COVID 前水準，屬回溫非爆發；短線明年展望可能稍微趨緩。

- **一般記憶體（非 HBM）**：HBM 大廠 HBM 做不完，把一般 DRAM 封裝外包給 ASEH；今年需求強，預計持續一段時間。

## 矽光子 — 空間已預留，EIC+PIC 黏接，2027 規模不揭露

- **先進廠空間已為矽光子預留**：若矽光子採 CoW 製程 → 進先進廠；傳統製程 → 進一般廠。
  - Broadcom（博通）CPU 相關矽光子業務已有接觸；具體數量管理層表示仍不確定

- **目前做法：EIC + PIC 黏接（bonding）**：不特別追求 3D 堆疊矽光子（若客戶同時做 3D，直接做完即可）；ASEH 技術上可以做，但未主動追這條路。

- **2027 年矽光子營收**：不揭露，管理層表示尚不明確。

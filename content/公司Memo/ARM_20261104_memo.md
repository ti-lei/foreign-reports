2026/11/04 ARM (ARM US)【統一國法訪談會議紀要】


20261104 ARM FY2Q27財報評論與MEMO 統一投顧 張榮森

評等調降至「中立」。

財報評論：

今天早上5點ARM公布FY2Q27(截至2026/9/30)財報：單季營收14.43億美元(+27%YOY，優於市場預期5%)，調整後EPS 0.52美元(+33%YOY，優於市場預期的0.47美元)。不過財報公布後盤後股價一度下跌近5%，目前跌幅收斂至1%左右，主要由於這季營收超預期完全來自波動較大的授權及其他收入(優於市場預期約16%)，而市場給予較高評價倍數、代表終端實際出貨的經常性權利金(不如市場預期約5%)，同時年增率僅8%，創近八季新低。

權利金增速放緩主要受到智慧型手機終端拖累。雖然AI代理帶動通用與客製化CPU調度需求，推升資料中心權利金年增翻倍(+100%YOY)，受到AWS Graviton、Google Axion、Microsoft Cobalt與NVIDIA Vera的ARM伺服器市占率由2024年的15%升至2025年逾50%，預計2026年底突破60%，同時車用與機器人權利金亦成長50%YOY；但DRAM漲價墊高手機製造成本並壓抑中低階出貨量，導致邊緣AI權利金年增率大致持平，僅靠Armv9(滲透率逾50%)與CSS(運算子系統)帶動單晶片權利金費率上升來抵銷出貨下滑。公司表示，記憶體漲價對手機造成的基期逆風將持續壓抑FY3Q27，直到FY4Q27(2027年1至2月)跨越基期後才會開始緩解。雖然公司預估2027年全球手機出貨量僅持平至年減1%，但在次世代CSS導入下行動業務仍有望重回雙位數成長，目前短期資料中心的高成長尚不足以完全彌補手機基期的壓力。

在自研資料中心處理器Arm AGI CPU方面，公司點名Meta為首要客戶且需求超越預期，過去90天已向台積電等晶圓代工廠、美光與三星及SK海力士等記憶體廠，以及載板與測試設備供應鏈取得額外產能，使FY2027至FY2028合計營收目標由前次逾10億美元提高至最高20億美元，首批商業交付排定於FY4Q27(CY1Q27)，並與Supermicro、Lenovo及華擎子公司永擎電子(7711)合作建置機櫃供甲骨文雲端(OCI)等客戶部署。不過，公司預期第一代AGI CPU毛利率僅30-40%(待下一代提高自研比例才往50%以上靠攏)，遠低於目前95%以上的毛利率，未來放量將結構性稀釋綜合毛利率；同時，為鎖定產能，公司於2026年10月簽署6.72億美元不可撤銷採購承諾，並預計於1H27預付2億美元晶圓產能預付款，導致自由現金流明顯下滑。

整體來看，雖然雲端CPU市占擴張與授權合約增加有利長期發展，但手機記憶體成本逆風壓抑短期經常性權利金增速，加上自研晶片持續推升營業費用、壓縮自由現金流並稀釋未來毛利率，FY3Q27財測驚喜有限還不足以支撐獲利預估與評價上修，考量目前ARM的PER還是高於60倍，且現在市場對AI類股的風險偏好明顯下降，因此調降評等至「中立」。

一、 財務與營運數據總覽

- 總營收（Total Revenue）：單季營收達 14.43 億美元（年增 27%），創歷史同期新高，且高於原指引區間中點 13.8 億美元（原指引區間為 13.3 億至 14.3 億美元）。此為連續第 5 個季度實現年增率超過 20%。
- 授權及其他營收（License & Other Revenue）：單季營收 7.73 億美元（年增 50%），創歷史同期新高。表現比內部預期高出約 1 億美元，主因客戶簽署長期合約承諾顯著加速。其中，與軟銀（SoftBank）的技術授權與設計服務協議貢獻 2.09 億美元（年增 17%），預計後續季度運作率（run-rate）維持在此水平。
- 權利金營收（Royalty Revenue）：單季營收 6.70 億美元（年增 8%），亦創同期新高。成長受 Armv9 與 CSS 費率提升及數據中心擴建推動，但部分被手機市場記憶體價格上漲擠壓出貨量所抵銷。
- 合約與營運指標：
  - 年化合約價值（ACV）：達 17.90 億美元（年增 12%）。
  - 授權協議數量：季內新增 3 份 Arm Total Access (ATA) 授權（活躍 ATA 訂閱數突破 60 份，含 1 位主要客戶首次簽署），並簽署 4 份 Compute Subsystem (CSS) 授權（數據中心與智慧型手機各 2 份）。
  - 晶片出貨量與生態系：單季合作夥伴回報之 Arm 架構晶片出貨量首次突破 100 億顆（年增 15 億顆），歷史累計出貨量超過 3,750 億顆。軟體開發者人數超過 3,000 萬人。
- 獲利能力與費用結構：
  - 毛利率：GAAP 毛利為 14.01 億美元（毛利率 97.1%）；Non-GAAP 毛利為 14.12 億美元（毛利率 97.9%）。
  - 營業費用（OpEx）：GAAP 營業費用 12.00 億美元（年增 27%）；Non-GAAP 營業費用 7.74 億美元（年增 19%），低於指引目標 7.80 億美元。
  - 研發與管理費用：Non-GAAP 研發費用（R&D）為 5.47 億美元（年增 17%），主因擴充工程團隊與開發次世代平台；GAAP R&D 為 8.57 億美元。Non-GAAP 銷售、一般與管理費用（SG&A）為 2.27 億美元（年增 25%）；GAAP SG&A 為 3.43 億美元。
  - 營業利潤與利潤率：GAAP 營業利潤 2.01 億美元（營業利潤率 13.9%）。Non-GAAP 營業利潤 6.38 億美元（年增 37%），Non-GAAP 營業利潤率提升 300 個基點 至 44.2%（上一財年同期為 41.1%）。
  - 每股盈餘（EPS）：GAAP 稀釋 EPS 為 $0.12（上一財年同期為 $0.22）；Non-GAAP 稀釋 EPS 為 $0.52（年增 33%），超越指引區間中點 $0.47（原指引區間為 $0.47 ± $0.04）。
- 資產負債表與現金流：
  - 過去 12 個月（TTM）Non-GAAP 自由現金流（FCF）達 10.96 億美元。單季 GAAP 營運現金流為 2.07 億美元，單季 Non-GAAP FCF 為 1.10 億美元。
  - 期末現金、現金等價物及短期投資總計 36.21 億美元（其中現金與現金等價物 32.51 億美元，短期投資 3.70 億美元）。

- FY27Q3 季度指引：
  - 總營收：預估為 15.40 億美元 ± 5,000 萬美元（隱含年增率約 24%）。
  - 授權及其他營收：預計年增 略高於 50%。
  - 權利金營收：預計季增 低雙位數（low-teens），年增 低個位數（low single-digit）。
  - Non-GAAP 營業費用：預估約 8.25 億美元。
  - Non-GAAP 稀釋 EPS：預估為 $0.56 ± $0.04。
- FY31 長期營運目標：
  - IP/CSS 授權與權利金業務：FY31 營收目標 100 億美元，Non-GAAP 營業利潤率 >65%。
  - Arm AGI CPU 獨立晶片業務：FY31 營收目標 150 億美元，Non-GAAP 營業利潤率 >30%。
  - 整體集團：FY31 總 Non-GAAP 每股盈餘目標 >$9。研發規模擴大後，FY26 至 FY31 之 Non-GAAP 營業費用 CAGR 預計放緩至 中雙位數（mid-teens）。

三、 各大業務板塊與技術細節

- Cloud AI / 數據中心：
  - 權利金表現與結構：數據中心權利金年增 100%，占總權利金比重已接近 20%。隨著核心數增加與 CSS 滲透，未來數年數據中心權利金預計維持 三位數（triple-digit） 成長。
  - 超大規模雲端業者（Hyperscaler）滲透率：頂級雲端業者的 Arm 架構伺服器市佔率從 2024 日曆年的 15% 提升至 2025 日曆年的 50% 以上。受 Google Axion、AWS Graviton、Microsoft Cobalt 及 NVIDIA 平台帶動，預估 2026 日曆年末將突破 60%。四家主要客戶（AWS、Google、Microsoft、NVIDIA）貢獻數據中心權利金的主體。
  - Head Node 轉向趨勢：連接加速器（GPU/TPU）的主節點 CPU 自 x86 轉向 Arm 的進度加快，例如 NVIDIA Vera Rubin 平台及 Google 宣布以 Axion 替換 x86 搭配 TPU v8。
  - 新架構與能耗技術：推出 Neoverse CSS N4，每插槽效能提升高達 2 倍，每瓦效能提升 25%。在能耗限制下，Agentic AI 工作負載要求每一吉瓦（GW）功耗下容納的 CPU 核心數自約 3,000 萬核 提升 4 倍 至 1.2 億核。
- Arm AGI CPU 獨立晶片業務：
  - 訂單與出貨時程：已取得延伸至 2027 日曆年之採購訂單，Meta 為首要客戶。商業交付定於 FY27Q4 展開。
  - 營收目標與利潤率：FY27 至 FY28 累計營收目標調升至 最高 20 億美元（up to $2B）。第一代晶片產品毛利率預估介於 30% 至 40% 區間，次世代產品目標達到業界標準 50%+。下一代（Gen 2）晶片研發沿用 18 至 24 個月 的行業節奏。
  - 供應鏈與效能測試：與 Supermicro、Lenovo、SROC 等 ODM 合作建置機架，部署於 Oracle Cloud Infrastructure (OCI)。在 Signal65 的測試中，Arm AGI CPU 每機架效能約為 AMD EPYC 9755 的 2 倍。
- Edge AI（智慧型手機、PC、消費電子）：
  - 手機市場：受記憶體成本上漲擠壓中低階手機量能影響，單季權利金年比持平。但 Armv9 架構滲透率已超過 50%。推出 CSS for Mobile 2（透過 SME2 提升 Agentic AI 效能 70%）與首款 AI 原生 Mali GPU G2-Ultra NX（同等功耗下幀率提升 4 倍）。預計手機業務受記憶體壓力的影響於 FY27Q3 觸底，下財年將恢復 雙位數以上 成長。
  - PC 與邊緣運算：Arm 架構 PC 占全球筆電出貨量 20%。Google 發布基於 Arm 平台的 Googlebook，NVIDIA RTX Spark 亦拓展至在地 AI 市場。
- Physical AI（車用與機器人）：
  - 營收與成長：單季權利金年增 50%，主因 ADAS 與車載資訊娛樂系統（IVI）採用率提升。
  - 生態系與技術應用：成立 Arm Total Design for Physical AI，已集結超過 80 家企業。Tensor Level 4 Robocar 單車整合超過 400 個 Arm CPU 核心。

四、 與上季及過去 90 天觀點之主要變化點

- AGI CPU 晶片業務營收目標上修：FY27 至 FY28 累計 AGI CPU 營收目標自 >10 億美元 調升至 最高 20 億美元（up to $2B）。主因為 Meta 等客戶需求強於預期，且在晶圓、載板、測試與記憶體等供應鏈產能保障上的確信度顯著增強。
- Hyperscaler 伺服器市佔率目標提高：原先目標為 2025 日曆年於頂級 Hyperscaler 達到 50% 市佔率，本季明確將 2026 日曆年末目標訂為 超過 60%。
- 授權營收超預期且管道延續性強：本季授權營收超出內部預期約 1 億美元。原預期授權成長會因高基期而放緩，但由於 Agentic AI 複雜度提升，客戶加速簽署 ATA 與 CSS，帶動授權 pipeline 未見放緩。
- 數據中心 Head Node 轉向速度加快：數據中心加速器配套 CPU 從 x86 轉向 Arm 作為 Head Node 的進度超出預期（如 Google Axion 替換 x86 搭配 TPU v8），提高數據中心權利金未來保持三位數成長之確信度。
- 手機市場逆風觸底時間確立：記憶體漲價壓抑手機出貨數量的逆風確定於 FY27Q3 達到影響峰值，並從次季（FY27Q4）開始基期放緩，下一財年手機權利金預計重回 雙位數以上 成長。
- 營業槓桿展現優於預期：在持續加大研發投入的同時，Non-GAAP 營業費用增幅控管在 19%，驅動 Non-GAAP 營業利潤率年增 300 個基點 至 44.2%。

Arm AGI CPU 晶片業務營收目標

確立至 FY28 財年底累計 10 億美元 的營收機會。需求雖達 20 億美元，但受限於晶圓、載板、測試與記憶體等供應鏈產能，正積極爭取額外產能以爭取高於 10 億美元的表現。

正式上修至 FY28 財年底累計營收目標至 最高 20 億美元（up to $2B）。已取得延伸至 2027 日曆年之多個客戶採購訂單（以 Meta 為首要客戶），對供應鏈產能保障之信心達到歷來最強。

AGI CPU 量產時程與毛利率

首批產品已交付給多個客戶，商業量產出貨排定於 FY27Q4 展開。第一代晶片毛利率預估介於 高 30% 至低 40%，長期目標在 2 至 3 年內達到 50%。

時程維持於 FY27Q4 開始商業交付。第一代毛利率維持 高 30% 至低 40%；第二代（Gen 2）預計於 18 至 24 個月後拉升，並透過提高自主研發比例達到 50%+ 的業界標準毛利率。

Hyperscaler 伺服器市佔率與 Head Node 轉換

數據中心權利金年增超過 100%，Neoverse 累計出貨突破 15 億核心。主要雲端業者（AWS Graviton、Google Axion、Microsoft Cobalt、NVIDIA Vera）持續擴大部署。

明確給出市佔率數據：頂級雲端業者的 Arm 伺服器市佔率從 2024 年的 15% 升至 2025 年的 50% 以上，並宣佈預計 2026 日曆年末將 突破 60%。此外，Head Node CPU 轉向 Arm 的進度加快（如 Google Axion 搭配 TPU v8、NVIDIA Vera Rubin），驅動數據中心權利金未來保持 三位數（triple-digit） 成長。

智慧型手機與邊緣端（Edge AI）逆風與復甦時點

記憶體價格上漲擠壓手機出貨，且影響範圍自低階擴及至中高階。雖受 Armv9 與 CSS 普及帶動使手機權利金維持成長，但全年代金額與權利金成長率自原預期的 20% 微幅調降至 high-teens（接近 20%）。

邊緣端權利金單季 持平。確立記憶體衝擊將於 FY27Q3 達到影響頂峰並開始跨越高基期。預計邊緣端權利金於 FY27Q4 恢復加速成長，下一財年（FY28）手機權利金預計重回 雙位數（double-digits+）以上 年增率。

授權營收（License Revenue）與 Pipeline 動力

單季授權營收 5.74 億美元（年增 23%），軟銀（SoftBank）協議貢獻 1.93 億美元，年化合約價值（ACV）年增 13%。原預期授權成長隨基期墊高將放緩。

單季授權營收達 7.73 億美元（年增 50%），超越內部預期約 1 億美元。軟銀協議貢獻 2.09 億美元。新增 3 份 ATA（活躍訂閱突破 60 份）與 4 份 CSS。指出 Agentic AI 工作負載需求驅動客戶加速簽約，授權 Pipeline 強度遠高於年初預期。

AI 數據中心總可尋址市場（TAM）觀點

回顧 3 月提出了 2030 年 CPU TAM 為 1,000 億美元 的觀點（高於當時業界預期的 500~600 億美元），並指出同行的預估值已升至 2,200 億美元，Arm 的預估顯得相對保守。

再次重申並認同業界將 AI 數據中心 TAM 上修至 2,000 億美元以上 的觀點。強調 Agentic AI 工作負載極度受限於 CPU 算力（CPU-bound），隨著 Agent 數量增加，對高核心數 CPU 的需求將呈現暴增。

** Physical AI（車用與機器人）業務**

提及 Physical AI 受 ADAS 與自主系統擴張帶動，對權利金成長做出強勁貢獻。NVIDIA 推出 Cosmos 3 與 Isaac GR00T/Jetson Thor 平台。

給出具體財務數據：Physical AI 權利金單季年增 50%。宣佈成立 Arm Total Design for Physical AI，集結超過 80 家企業合作夥伴。Tensor Level 4 Robocar 單車整合超過 400 個 Arm CPU 核心。

營業費用（OpEx）與營運槓桿（Margins）

Non-GAAP 營業費用 7.33 億美元（年增 18%），低於指引約 2,700 萬美元，主因研發工具使用時點差異。Non-GAAP 營業利潤率為 41%（年增 200 個基點）。

Non-GAAP 營業費用 7.74 億美元（年增 19%），低於指引的 7.80 億美元。Non-GAAP 營業利潤率提升至 44.2%（年增 300 個基點），展現出營收成長速於費用擴張的顯著營運槓桿。

技術架構與新產品發布

著重於 Windows on Arm PC（Snapdragon）、Google AI Chromebook 及 NVIDIA RTX Spark 平台在在地 AI 與 Agentic PC 的應用。

發布多款具體架構：數據中心推出 Neoverse CSS N4（每插槽效能提升最高 2 倍）；手機端發表 CSS for Mobile 2（Agentic AI 效能提升 70%）與首款 AI 原生 Mali GPU G2-Ultra NX；PC 端 Arm 佔全球筆電出貨已達 20%。

問題： 關於 Arm AGI CPU 晶片業務，公司預期至 FY28 財年底的五個季度內將實現接近 20 億美元 的營收，背後支撐強烈信心的因素為何？在供應鏈產能獲取方面進展如何？此外，除了主要客戶 Meta 之外，是否已與其他客戶簽署合約承諾？

問題： 從財報數據計算，單晶片平均權利金費率（royalty rate per unit）呈現年增中個位數的趨勢，這是否代表長期的結構性趨勢，抑或是受單季產品組合影響？各大業務板塊的權利金動能為何？

回答： 單季晶片出貨量高達 100 億顆，整體平均權利金會因每季度的產品組合波動，其中手機晶片的平均費率低於伺服器與 Physical AI，因此不宜將單季總平均作為長期預測基準。若分業務板塊來看：智慧型手機權利金表現相對平緩；Physical AI 年增 50%，形成整體拉動；數據中心則受核心數增加與 CSS 滲透率提升推動，預計未來數年將維持 三位數（triple-digit） 成長。此外，頂級雲端業者的 Arm 伺服器市佔率預計於 2026 年底 突破 60%，且連接加速器的主節點（Head Node）CPU 出現從 x86 轉向 Arm 的加速趨勢（如 NVIDIA Vera Rubin 平台以及 Google 將 x86 替換為 Axion 連接 TPU v8），進一步鞏固了數據中心權利金長期快速成長的確信度。

問題： 在 AI 數據中心市場中，Arm 與 x86 架構競爭並取得優勢的核心機制為何？雖然在 OCP 上展示的 AGI CPU 具備優異的機架效能，但競品亦宣稱其 CPU 擁有最佳每瓦效能，Arm 的勝出關鍵與產品策略為何？

回答： 勝出機制可從兩個維度分析：其一，在 Hyperscaler 客製化自研晶片（如 Amazon、Google、Microsoft）層面，客戶能在晶片與系統架構（包含資料傳輸、DPU 及儲存）獲得極高的設計靈活性與轉換自由，Arm 提供市場上最優異效率的核心，協助客戶打造最具成本與能效優勢的特化 SoC 與機架系統；其二，在 Arm AGI CPU 獨立晶片層面，由 Signal65 進行的第三方獨立測試證實了其在每機架效能與每瓦效能上的優勢。無論是提供客製化 IP 還是銷售獨立晶片，Arm 都能以極高的運算效率與效能價格比滿足客戶需求。

問題： 關於 Arm AGI CPU 參考設計與合作夥伴，目前是否已與多家 ODM 廠商合作？主要鎖定企業私有雲還是超大規模客戶？此外，預計至 FY31 達到 150 億美元 AGI CPU 營收目標的過程中，最大的驅動因素是核心數增加還是單價（ASP）提升？

回答： 目前合作的 ODM 夥伴包含 Supermicro、Lenovo 及 SROC，主要負責建置機架並部署於 OCI 等數據中心環境。在營收規模擴張的驅動因素中，單晶片核心數（core count）的急速增加為最關鍵的拉動力。由於 Agentic AI 工作負載中，每個 AI Agent（例如 Muse agent）通常需要在單一 CPU 核心上的虛擬機器中運行，使得 AI 工作負載極度受限於 CPU 算力。這推動了數據中心對高核心數 CPU 的強烈需求，而 Arm 在核心層級的每瓦效能優勢將成為最大的競爭優勢。

問題： 關於上修至 20 億美元 的 AGI CPU 晶片營收目標，在 FY27 財年的 9 月或 12 月季度（Q2 或 Q3）是否會有營收貢獻？

問題： 數據中心占總權利金比重目前是否已接近三分之一，並預期於下財年（FY28）進一步朝 40% 至 45% 邁進？

問題： 在 Cloud AI 數據中心業務中，客戶集中度狀況為何？前幾大客戶是否貢獻了絕大部分的數據中心權利金？

問題： 在第一代 AGI CPU 取得市場初步成功後，第二代 AGI CPU 的研發時程與規劃為何？此外，鑑於算力與網路傳輸緊密結合，公司是否計畫在未來的產品組合中加入更多網路與高效能 I/O 能力？

回答： 第二代 AGI CPU 產品將遵循業界約 18 至 24 個月 的標準量產拉升週期發展。在系統能力擴充方面，公司著眼於整體機架系統效能，資料進出系統的傳輸效率與 CPU 本身同樣關鍵。公司正積極研發與評估包含網路、特定 I/O 及高速連接等相關技術，以在未來的機架級解決方案中創造更大的產品差異化。

問題： 本季授權及其他營收達 7.73 億美元 表現亮眼，其中是否包含架構授權協議（ALA）？該營收水準是否代表未來的常態結構？對下財年的整體展望為何？

回答： 本季授權營收的主體為 Arm Total Access (ATA) 與 Compute Subsystem (CSS)，架構授權協議（ALA）極少發生。雖然授權營收單季可能因大合約簽署時點而波動，但由於 Agentic AI 工作負載推動客戶對多元技術與新授權的需求，授權 Pipeline 顯著強於年初預期。ATA 與 CSS 授權的強勁簽署，將在未來 12 至 24 個月 內轉化為設計定案與權利金成長。此外，手機市場記憶體價格上漲造成的低基期效能影響將於 Q3 結束，後續季度基期轉為有利，整體形勢非常良好。

問題： 隨著未來 CPU 核心數增加與算力提升，單核心的價值或定價（per core dollar value）是否有進一步調升的彈性空間？

回答： 考量到記憶體價格上漲及數據中心整體建置成本上升，公司在產品定價上保持謹慎，但對於具備更高核心數與強大算力的大型晶片，確實存在價格彈性（pricing elasticity）與進一步調升定價的空間。

問題： 若明年全球智慧型手機出貨量持續年減，手機權利金營收趨勢將如何發展？

回答： 市場研調機構預估明年全球手機出貨量約為持平（-1%）。隨著記憶體價格上漲對出貨量的衝擊趨於穩定，加上 Armv9 滲透率已 突破 50%，以及更多合作夥伴採用費率更高的次世代 CSS 架構，手機權利金業務預計將顯著超越整體市場成長，實現 雙位數（double-digits+）以上 的年增率。

問題： 關於 AGI CPU 平台，Arm 是否具備足夠的供應鏈規模與談判籌碼，以取得擴產所需的足夠產能，成為 CPU 市場中具影響力的主要競爭者？

回答： 雖然 AGI CPU 是 Arm 的首款獨立晶片產品，但 Arm 與台積電（TSMC）以及主要記憶體廠商（Micron、Samsung、SK Hynix）擁有長達數十年的合作關係。公司將 AGI CPU 視為一項 5 至 10 年 的長期戰略業務，並一直積極與全球供應鏈夥伴合作，以確保獲得足夠的產能來支持長期強勁的市場需求。

問題： 為 AGI CPU 取得更多供應鏈產能是否伴隨更高的整體成本？這對第一代與未來次世代產品的毛利率（Gross Margin）有何影響？

回答： 供應鏈整體成本（特別是記憶體價格）確實對產品毛利率造成壓力。第一代 AGI CPU 晶片產品的毛利率預估落在 30% 至 40% 區間；隨著公司累積更多晶片設計與供應鏈管理經驗、並逐步增加自研比例，未來的次世代產品目標將達到業界標準的 50% 以上 毛利率。

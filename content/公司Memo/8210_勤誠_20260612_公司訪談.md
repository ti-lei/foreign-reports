# 勤誠 (8210) | 公司訪談

## 財務概況與全年指引

- **Q1 2026 毛利率**：32.8%，為近年高點
  - 2025 年全年平均毛利率 30%
  - 2019 年前次高峰（第一筆大型 CSP 訂單），2020–22 年因 Second Source 引入與疫情供料壓縮後回落，2023–24 年 AI 帶動回升

- **營收成長指引（全年）**：年初給 20%+，逐步上修至 30%，現在更新為 **40%+**
  - Q2：QoQ 成長 5-10%，持續增長
  - 管理層表示仍有繼續上修空間

- **財務體質指標**：
  - CCC（Cash Conversion Cycle）：疫情期間 >100 天，現連續數季低於 50 天，仍在持續優化
  - 股利政策：Payout ratio 45%+
  - 發行兩次 CB（可轉債）用於擴廠，每次 Dilution 均控制在 < 3%

- **毛利率中長期指引**：基準 28–29%（3–5 年後，考量 Rack 佔比擴大的稀釋效應）
  - 近期波動因素：NPI 轉 MP 速度、新產品組合（Rack vs Chassis）、匯率

## 業務模式：OBM / JDM / ODM 三軌並行

- **OBM（Own Brand）**：標準產品，佔總營收 **15–20%**
  - 面向全球約 150–200 家 channel / distributor，服務中小型客戶（Enterprise 市場）
  - 功能：平衡風險，避免完全依賴大型 CSP

- **JDM（Joint Design）**：與 SI（微影廣雅、鴻海等）聯合設計，SI 彙整終端需求後共同開發
  - AI 趨勢下的主力增長模式，大型 CSP 訂單主要走此路徑

- **ODM/OEM**：部分熟悉專案的客戶或 SI 直接委託量產，勤誠負責生產與驗證

- **產品線演進時序**：
  - 1983：PC 機殼起家
  - 2009：切入 Server（HP、Dell 等）
  - 2023：AI Server（HGX 主要供應商）
  - 2025：Rack Component（降噪櫃/Silencer）
  - **2026**：正式切入完整 Rack；取得 [[NVIDIA]] MGX Rack 供應商資格（2026 年 5 月）；新切入 CDU Rack（透過散熱合作夥伴）

## Rack 業務：市場重塑下的新機會

- **現況佔比**：
  - 2025（Rack Component 階段）：**5–10%** 總營收
  - 2026（完整 Rack）：**10–15%** 總營收
  - 目標 2027：**>20%** 總營收

- **Rack 出貨形態**（兩種，均歸入 Rack 營收）：
  - 純 Rack 機櫃本體
  - Rack + 內部 Server Chassis 一起出貨（L3 機構件組合，非 L10 完整整機）

- **Rack 毛利率**：
  - 傳統標準 IT Rack（非勤誠定位）：15–20%
  - 勤誠主攻客製化 Rack：**20–30%**
    - 低於整體 Q1 毛利率 32.8%，放量後將小幅稀釋整體毛利率

- **Rack 產能計畫**：
  - 現況：50–70 櫃/週
  - 馬來西亞廠開出後（預計 Q3 2026 末）：100+ 櫃/週
  - 2028（馬來西亞 + 美國全開）：1,000–1,500+ 櫃/週目標
    - 馬來西亞 + 美國新廠：各有 **七成**產能規劃支援 Rack

- **競爭格局**：Rack 市場正在重塑，過去以標準規格為主（未上市金屬加工廠主導）；現在因 Server 與 Rack 必須整合設計，CSP 直接找 Chassis 供應商擴展做 Rack
  - 現遇同業：Reto（高品質設計、CSP 關係強，但客製彈性較低）、ODM 廠（鴻海）
  - 中資廠商：主要在大陸標準產能與部分台商，高端客製化競爭較少

## 生產佈局擴充

- **NPI 廠**（前端打樣設計）：中國 2 廠、台灣 1 廠、**美國 1 廠（2026 年 3 月啟用）**
  - 每廠月產能約 1–2 萬台
  - NPI 案子數量：前年 30+ 個 → 現在 **80+ 個排隊中**，顯示需求大幅增加

- **MP 廠**（量產）：中國 2 廠、台灣 1 廠；**馬來西亞 + 美國興建中**
  - 每廠月產能約 8–10 萬台
  - **馬來西亞**：預計 Q3 2026 末啟用
  - **美國**：預計 2026 年底啟用

- **設計到量產流程優勢**：
  - NPI 廠配置 RD 在地與客戶溝通 → 設計圖傳回總部開模 → 模具共用管理（leveraging 舊模具）→ 量產廠執行
  - 模具共用率：單一案件演進中可共用約 40–60%，降低客戶 NRE 投資

## 客戶組合與市佔率

- **整體 Chassis 市佔**：全球約 **10–13%**（以 Level 3–6 出貨量 / 全球伺服器出貨量估算）

- **A 客戶**（美系最大 CSP）：佔總營收 **40–50%**
  - General Server：市佔 30%+
  - HGX：主要供應商，分配比重 **50%+**
  - ASIC：次要供應商，分配比重 **30–40%**
  - MGX（GB200/Rubin）：現持續觀望；協助出貨 GB300 與 Rubin，分配比重約 50%

- **B 客戶**（中系大型 CSP）：佔總營收 **10–15%**
  - 協助其自研晶片 ASIC 及 General Server

- **C 客戶**（美系，第三大）：佔總營收 **5–10%**
  - HGX 高密度機種 + MGX（GB300）+ 部分 Rack

- **M 客戶**（美系，第四大）：佔總營收 **0–5%**
  - General Server；待馬來西亞廠認證後預計切入 MGX 專案

- **T 客戶**（中企）：佔總營收 **1–3%**

- **Non-CSP**（透過 SI 如微創等）：切入 Dell、XAI 等，主要做 MGX + General Server

## 原物料與定價

- **主要原料**：鋼材（Chassis）、鋁材（Rack 部分）
  - 兩者均採月報價制，已與供應商簽訂長約鎖住成本
  - 客戶端：目前如有大幅漲價情況客戶願意吸收，現階段尚無需大幅調價需求

## 供應鏈關係

- **客戶**：A 客戶（美系大型 CSP）— 40–50% 營收，HGX/ASIC/MGX 全線供應；B 客戶（中系 CSP）— 10–15%；C/M 客戶（美系）— 各 5–10% / 0–5%；[[Dell]] — Non-CSP 路徑（透過 SI）；XAI — Non-CSP 路徑
- **供應商**：鋼材廠（月報、長約鎖定）；SANYO DENKI / [[Nidec]] / SUNON（風扇模組）；King Slide（滑軌）；散熱合作夥伴（CDU Rack 零件供應）
- **競爭對手**：Reto — CSP 關係強但客製彈性低，部分 CSP 引入為 second source；[[鴻海]] — ODM 領域偶遇；未上市金屬加工廠 — 標準 Rack 原主力，現格局重塑中

## PQ 拆解

### AI Server Chassis（HGX / ASIC / MGX）
- **Q（量）**：NPI 排隊案件 80+ 個（成長驅動，前年僅 30+）；A 客戶 HGX 維持主供，MGX 持續協助出貨 GB300 / Rubin
- **P（價）**：客製化設計收取 NRE；舊專案隨時間模具共用比例提升，NRE 收入遞減但量產毛利穩定；Q1 整體 GM 32.8%

### Rack（CDU Rack / IT Rack / 降噪櫃）
- **Q（量）**：2026 佔總營收 10–15%（去年 5–10%），目標 2027 >20%；現產能 50–70 櫃/週，馬來西亞開出後達 100+ 櫃/週
- **P（價）**：客製化 Rack GM 20–30%（低於 Chassis，放量後將稀釋整體毛利率）；標準 IT Rack 行業 GM 15–20%（非勤誠主力）

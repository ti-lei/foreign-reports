# 雙鴻 (3324.TWO) Call Memo | 2026-11-23

雙鴻 (3324.TWO) Call Memo
類型：法說會
主講人：雙鴻公司經營團隊
時間：2026.11.20 15:30

本次法說/私訪內容
公司簡介
營運摘要
•    1. 公司基本資訊：雙鴻科技成立於 1999 年，2005 年上櫃，目前股本為 NT$9.31 億元。全方位散熱解決方案涵蓋氣冷（HP/VC/3DVC…散熱模組）與水冷（水冷板 Cold Plate、分歧管 Manifold、CDU 水冷分配裝置、快接頭 Quick Disconnect 等 Rack System）。
•    產品技術轉型歷程：
•    2023年前：為純氣冷散熱模組（Air Cooling Component）供應商。
•    2023年起：因應 H 系列（H100 世代）水冷需求，轉型為 System / Solution Provider，可提供 CDU、Manifold、Cold Plate 及系統級水冷架構。
•    2025年：跨入均熱片（VC / 樂片）產業，2Q25 推出雙金屬技術。
•    2026年：推動整體水冷系統模組化（Modularization）。
•    2. 3Q26 產品組合（Product Mix）
•    伺服器（Server，含 AI 與傳統伺服器）：營收占比 81%（帶動整體伺服器與周邊達 85%）。
•    水冷（Liquid Cooling）：占整體營收 62%。
•    氣冷（Air Cooling）：占整體營收 19%。
•    顯示卡（VGA / Graphics Card）：營收占比 10%。
•    個人電腦（PC / Notebook）：營收占比 4%。
•    其他 Consumer 應用：營收占比約 5%。
•    3. 3Q26 財務表現與毛利率分析
•    營收表現：3Q26 營收 QoQ 12.5%。
•    毛利率不及預期主因：
•    Consumer 消費型市場疲弱：高階應用市場銷售不及預期，致量價雙縮，經濟規模未達，固定成本偏高。
•    新產品/新市場試產費用高：3Q26 試產（Pilot Production）與新市場導入項目較多，前置費用與成本提升。
•    1-3Q26（前三季）累計財務數據：
•    營業費用率：降至 12.1%，費用控管持續改善。
•    毛利率區間：累計毛利率維持在 30.63%-35.9% 區間。
•    簡報歷史數據對照（2025年 全年）：營業淨額 NT$23,276,344 千元（YoY 47.5%）；營業毛利率 27.4%；營業利益率 14.0%；EPS 28.26 元。
•    4. 2027年 營運展望與成長動能
•    營收結構目標：
•    伺服器占比：提升至 90%（水冷占全集團營收 80%，氣冷伺服器占 10%）。
•    Consumer（DS / PC / VGA）：降至 10%。
•    三大成長動能：
•    ASIC 客戶轉水冷：ASIC 客戶過往採用氣冷，4Q26 開始水冷量產出貨，2027年 為 ASIC 水冷放量元年。
•    Module Design（模組化設計）提升 ASP：氣冷時代單一 Component 約 $50 美元；水冷時代採 M Design 包辦 CPU、GPU 與整體散熱架構設計，單價與產值大幅提升。
•    散熱下沉至周邊元件：因應 PUE < 1.5 要求與電力限制，Memory（記憶體）、Immersion（浸沒式）、SSD、Power Supply（電源）等均將導入水冷。
•    5. 雙鴻2 簡報現場說明
•    算力需求與建置：算力需求持續強勁，完全未見需求下滑。
•    ASIC 營收占比：2026年 ASIC 相關占比為 0-10%（以氣冷為主），2027年 ASIC 水冷占比預估躍升至 30-40%。
•    下世代晶片出貨時程：4Q26 開始拉貨，2027年 加速滲透。
•    水冷毛利率目標：水冷產品毛利率目標維持 30-35%，高客製化產品毛利率更高。
•    關鍵財務數字：7M26 單月 EPS 6.4 元；3Q26 單季 EPS 11.5 元。
QA
•    Q1：2027年 整體營收成長率與毛利率展望為何？
•    A1：2027年 營收成長性不會比 2026年 差，整體 Topline 營收與獲利目標都會更好。毛利率相較 2026年 會持續提升，主因水冷產品毛利率基本高於 35%，且高客製化 Module Design 與水冷轉型大幅放大經濟規模。
•    Q2：3Q26 試產費用影響程度為何？4Q26 營運展望與 Consumer 毛利率改善情況？
•    A2：3Q26 試產費用影響金額約 1 億元多。Consumer 業務因終端售價過高致量價雙縮，加上中國大陸廠區生產未達經濟規模，拖累 3Q26 毛利率。4Q26 在 ASIC 水冷與新案量產帶動下，營收預計呈 QoQ 雙位數 成長，毛利率將顯著改善。
•    Q3：目前產能狀況為何？泰國廠擴產進度與規劃？
•    A3：目前水冷產能吃緊。泰國二期廠房於 2025年 動工興建，建廠週期約 1.5 年，預計 2027年 投產。泰國三期土地已購妥並開始規劃無塵室，採「先蓋廠房、依專案與客戶需求陸續進駐設備」策略。
•    Q4：ASIC 客戶（AWS與 M客戶）水冷導入時程與供貨份額？
•    A4：雙鴻在 AWS取得約 30% 供貨份額（由 3-4 家供應商均分）。AWS於 11M26 開始小量出貨水冷，12M26 出貨放量，1H27 為顯著貢獻期。M 客戶採半年迭代策略，下一代晶片水冷預計在 2H27 至 2028年 大幅放量。
•    Q5：NVIDIA GB200 / GB300 / NVL 機架產品滲透率與水冷板（Cold Plate）ASP 變化？
•    A5：GB200 交貨窗口較短、量較少；GB300 取得良好平衡點，市占份額向上提升。水冷板設計由單片轉為兩片（或多片），加上高客製化與高複雜度設計，平均單價 ASP 顯著提高。
•    Q6：均熱片（VC ）營收占比與產品應用定位？
•    A6：均熱片營收占比低於 5%。目前主攻 CPU 散熱（如 SP7 架構），包含 AMD 與 Intel 高階應用，定位為全方位散熱技術整合，非單純衝刺單一零組件營收。
•    Q7：2026年 與 2027年 的資本支出（CAPEX）規劃為何？
•    A7：2026年 與 2027年 資本支出預算均落在 NT$3.5B-4.5B（NT$35-45 億元）區間，主要用於泰國廠三期興建與產線自動化升級。
•    Q8：CSP 廠與 GPU 大廠專案調整對雙鴻的實際影響為何？
•    A8：雖曾有專案短暫退出，但客戶於不到一個月內即要求重新回歸驗證，GB200/GB300 正常進行。3Q26 為新舊平台交替與試產低谷，4Q26 起 ASIC 水冷拉貨啟動，營運明顯回升。
•    Q9：記憶體（Memory）水冷與微通道/點膠技術佈局進展？
•    A9：雙鴻最早投入 Memory 水冷點膠與微通道技術，並率先通過首家客戶驗證。Memory 水冷搭載率隨 HGX/HPC 高階伺服器發展，預計在 2027年 顯著增長。
•    Q10：2028年 營運極端模擬與 Non-China 產能布局？
•    A10：公司已進行長達三年的極端情境模擬，即便無 AI 爆發，傳統 Server 與 NB 業務仍能維持穩定獲利。CSP 客戶自 2020年 起即嚴格要求 Non-China 產能，泰國廠目前占總營收 25%，中期規劃中國大陸廠區占 60%、泰國廠占 40%，泰國廠享 BOI 免稅與高度自動化優勢。
•    Q11：ASIC 水冷板與 GPU 水冷板在單價（ASP）與技術上的差異為何？
•    A11：GPU 水冷板趨向標準化；ASIC 水冷板屬於 Multiple Package、非均溫結構，客製化與技術門檻更高，ASP 與利潤空間優於標準品。
•    Q12：2028年 訂單可見度與專案開發週期？
•    A12：專案開發週期約 1 年（過去為 1.5-2 年），製造與備料週期約 4-6 週。2028年 產業輪廓與訂單預計在 2Q27-3Q27 即可明確掌握。

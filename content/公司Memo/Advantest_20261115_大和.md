## Advantest 爐邊會議重點

公司前言

本週雖有市場上的事件(美國期中啦!), 但詢價及需求強度還沒有出現特別變化. 公司內部的重點在於如何維持提升供給能力的節奏. 全球據點的供應鏈管理正在做各種情境規劃, 法說後Q&A提到內部有SoC tester年產1萬台, 2萬台的討論, 公司正全力朝這個方向推進.

公司強調需求持續強勁, CPU量產提早放量是本季最大變化. 營收規模目前由公司的供給能力決定. SoC tester年產能已在2Q (7-9月)突破5,000台, 比原目標提前約半年, 1萬台的時程也希望再提前, 但時間還沒有公布. 2H OPM受部材成本上升影響, 較1H低約4ppt. 公司正與客戶議價調漲售價, 成效會影響明年OPM. 2027 tester市場成長預期不低於過去兩年50%以上的CAGR, 正式TAM將在1月財報公布.

其他重點

客戶改買最高配置tester, 推升單價及GM: CPU量產比預期提早拉升, 是本次上修的主因. 晶圓代工的產能可能隨時在CPU, GPU及ASIC之間切換, 所以客戶傾向購買三者都能量測的最高配置tester. 先進封裝讓模組片數增加, 例如數位模組由3片增至約5片. 公司表示, 相較約5年前, 平均單價上升約10-15%. 追加的多是高獲利模組, 因此有助推升GM. AI/HPC約佔Compute & Communication的70-80%, 手機APU已不是主要驅動力.

營收由產能決定, 關鍵在零組件: 產能沒有多餘buffer, 需求仍高於產能, AI半導體需求還沒有全部滿足. SoC tester年產能在2Q突破5,000台, 比原計畫提前約半年. 提前達成主要靠預先採購長交期零組件. 1萬台目標會再提前, 但時程還不能公布. 營收上行或下行都看零組件到貨, 最大風險是記憶體, PCB基板及玻璃材料, 這些都要和data center投資搶料. 公司認為供給雖吃緊, 還不至於影響市佔.

2H OPM受成本壓抑, 漲價成效決定明年獲利率: 2H OPM較1H低約4ppt, 主因是零組件成本上升. 公司正與客戶議價調漲售價, 但2H還沒有反映漲價效果. 調漲的成果會影響明年OPM. 市場面, 公司認為2027 tester市場成長很難低於過去兩年50%以上的CAGR. 這是以金額計算, 已包含ASP上升. 正式的2027 TAM將在1月財報公布.

Q&A

2027 outlook

CEO表示明年沒有減速感, CAGR 50%會持續到2029?

正確說法是過去兩年CAGR 50%以上, 從環境來看很難想像2027會低於此水準. TAM正在最終檢視, 2027 TAM預計在1月財報公布.

過去兩年tester市場成長50%, SoC tester成長更多? 如圖表所示.

SoC tester到2027沒有減速感? 是.

以公司產能狀況, 2027即使沒有減速也能滿足嗎? 或者為了提升市佔, 正在建構超過強勁成長率的產能? 要看明年1月公布的數字. 公司正大幅加速擴產, 以便在客戶需要的時點滿足需求.

2027 tester市場不低於50%成長, 是台數還是金額? 營收金額(市場規模), 也包含高配置tester增加帶來的ASP上升.

明年OPM如何思考? 第一是高獲利產品佔整體營收的比重. 第二, 公司預期本年度2H OPM會受部材成本上升壓抑. 目前正與客戶進行價格談判, 針對成本上升部分請求漲價. 漲價成功程度及幅度會影響明年OPM.

營收成長可拆解為半導體數量成長, 市佔提升, 技術變化使測試負荷增加, 以及單價上升. 若半導體需求本身成長放緩, 市佔, 測試負荷及單價是否較具主導性? 半導體數量對營收的影響大還是小?

就成長率而言, 數量影響大. 數量成長帶動的比重, 大於第二項因素(複雜度). 但不能說是壓倒性.

財報上修

本次財報有新變化嗎? 7月時CPU需求增加是變化點, 10月以後是否出現新的成長故事?

沒有大變化. 全年上修是因為2Q-4Q CPU生產數量比公司預期更早拉升. 客戶從2Q起希望tester配置能同時量測CPU, GPU及ASIC, 公司增加產能來回應, 因此結果高於預期. CPU生產數量提前是本次的變化點.

本次上修是因為產能已超過需求並保有buffer嗎?

沒有超過需求的buffer. SoC tester年產5,000台以上原本目標是本年度末, 已提前約半年實現. 下一步的1萬台計畫也希望大幅提前, 時間還不能明言. 正確說法是需求強勁, 公司正在擴產, 以便有餘裕地消化需求. 公司提早採購部材來加快擴產, 所以需求轉強時能多出貨. 這不是因為原本就有餘裕, 而是努力提前的結果.

2H雖然能見度不高, 明年是否可望提升?

若已取得的客戶持續採用使確認度提升, 客戶數增加, 且不只新增tester, installed base也開始採用device interface, 就能較有信心地計入. 1H在客戶爭取上有進展並認列營收, 持續性取決於公司接下來的努力.

公司計畫中3Q與4Q如何分配?

擴產通常逐步拉升, 因此預期4Q營收高於3Q. 其中memory tester從3Q到4Q會呈階梯式上升.

所以目前產能幾乎等於需求? 需求還要再強一些.

所以產能等於出貨台數及營收? 目前是這樣. 公司想保有buffer, 但不是靠消耗buffer, 而是靠提早採購部材來實現前倒.

5,000台是否在9月底已達成? 在2Q (7-9月)期間突破5,000台.

6個月前提到2027/3底達5,000台, 現在更新後2027/3底是幾千台?

無法回答. 下一目標1萬台何時實現, 確認度還沒有提升, 所以本次沒有提及. 公司正在努力提前, 但不會在過程中公告例如某時點達7,000台.

3個月前說希望1萬台提前1年, 這次是否比當時更提前? 3個月前並沒有說提前1年. 但與3個月前相比, 5,000台達成時間已經提早, 加上這些提早的進度, 1萬台希望達成的時點也提早了.

驚人的讓時程能提前的原因來自部材還是公司生產體制? 零組件. 公司預先採購長交期部材, 短交期部材則可在下單後較快取得, 因此能提早組裝.

前次財報1萬台的印象是2028底至2029, 2027年內達成是否有困難?

目前無法回答, 能回答時會再說明. 這需要各方面都到位, 並非刻意保留. 公司也想讓客戶安心, 正在確認採購的確定度, 評估大約何時能實現.

本次capex上修的背景? 擴產主要透過外包組裝實現. 外包時有一些治工具適合由公司投資後consign給外包商, 這對雙方最有效率. 隨各項擴產提前, consign用治具等設備略為增加. SoC tester及memory tester都有.

CPU, GPU, ASIC, SoC, memory

CPU是類似NVIDIA Vera的類型, 還是其他客戶的CPU? 哪裡比較強?

各客戶的交貨時點及力道有一定差異. 但整體而言, AI推論帶動CPU對GPU的比率上升, CPU需求全面升溫.

2Q時GPU, ASIC及CPU等AI半導體在SoC測試中的比重大約多少?

這很難回答. 就需求面來看, GPU仍維持非常強勁的高水準需求, ASIC及CPU數量則各自成長. 困難之處在於客戶預先購買可以量測所有晶片的tester, 最終用途由晶圓代工與fabless之間的wafer allocation決定. 從fabless角度來看, GPU仍強.

SoC tester中Compute & Communication營收是否幾乎都是GPU, ASIC及CPU?

常被問到手機APU是否仍有tester出貨, 答案是有. 量產據點UTR非常高, 手機APU轉換到下一代製程節點或功能升級時, 測試時間拉長, 項目增加. 若生產數量計畫相同, 就需要更多tester, 所以在UTR很高時會出現追加訂單. 不過整體而言, 手機APU的tester需求已大幅縮小.

手機大約佔多少? 10-20%左右? 沒有揭露, 無法量化. 2022以前手機是最大需求來源, 2023以後HPC成為最大事業driver.

AI/HPC佔Compute & Communication約70-80%的印象是否接近? 不遠.

客戶希望CPU, GPU及ASIC都能量測, 是否代表不論哪種晶片, 高配置tester的需求都在增加? 是. 各自的配置其實略有不同. 但有餘裕的全能配置可以在晶圓代工的wafer allocation突然轉向CPU或又轉回ASIC時立即支援量產, 因此以最大配置採購的比率上升.

目前AI/HPC SoC tester單價大約多少? 原本印象是Y2-3e, 這個區間是否又往上一階?

不回答單價. 配置範圍很廣, 模組片數越多, 單價上升越多, 達到Y數e等級. 採用先進封裝的晶片內含更多半導體且複雜度提升, 例如數位模組原本3片, 現在需要約5片. Device power supply也從1種變成多種且各用數片. 相較約5年前, 平均單價上升約10-15%.

SoC tester是否線性上升? 比較接近線性.

memory tester呈階梯式上升有什麼特別原因? 公司生產所需部材的到貨狀況.

memory tester產能擴充計畫及現況? 與SoC tester一樣加速增產. SoC tester採V93000平台策略, memory tester則依各機種需求分別提升產能. 客戶看到相關資訊會在意自己想要的機種擴產節奏, 所以不揭露台數目標.

雖然不揭露台數, 產能每次增加幾成之類有評論嗎? 內部目標是朝與SoC類似的方向大幅提升.

SoC在2025約3,000台, 本年度中已達5,000台以上, memory是否用相同節奏擴產?

SoC與memory市場起飛的時點不同. 2023 memory tester市場規模$1.1b, 2023至2024因HBM需求急增升至$1.9b, 之後成長趨緩. 目前記憶體需求非常強, 記憶體客戶正在建廠增加wafer output. Output增加的2027, 2028, tester需求自然比過去兩年高. 公司過去約20年觀察到, 記憶體的速度及容量要先準備好, SoC性能提升才能發揮. PC及手機都一樣, 先是記憶體需求上升, 接著才是SoC. 因此當需要為memory tester需求做準備時, 公司會大幅提高memory tester擴產目標. 輪到SoC時, 則提高SoC擴產步調, 這些都在短期內調整.

GM/OPM推升

單價上升是否直接推升GM?

大致是, 因為常追加搭載高獲利模組. 只購買license時, 推升幅度更高. 一般模組升級的推升幅度則較小. 全部平均下來, 單價上升約10-15%.

服務及其他事業利潤率近期上升, 今年度是否有變化?

這個部門包含support service (以維護保修合約為主), 以及nanotechnology產品和過去併購公司的消耗品device interface. Device interface是高性能SoC用的test board及IC socket, 單價高, 屬於高獲利產品. 併購後公司持續擴產並爭取客戶, 逐漸看到成果, 開始超過損益兩平. Support service成長明顯, 來自裝機台數增加及單價上升. 系統配置變大, 保固期滿後的維護合約單筆規模也變大.

1H OPM 27.8%, 隨SoC tester需求增加, 高階device interface及socket需求也增加, 此水準能否維持甚至提升?

Others中的device interface仍在爭取客戶階段, 還沒有穩定到tester台數增加就會穩定成長. 因此對2H的看法沒有那麼強.

2H還沒有納入漲價抵銷的效果? 是.

零組件與原物料成本上升壓低OPM多少?

1H幾乎沒有受到零組件成本上升影響. 與1H相比, 2H OPM下滑4ppt, 以全公司營收來看, 影響大致接近此幅度. 嚴格來說, 營收增加也會使SG&A上升, 但最大的壓抑因素是部材成本上升.

FY26業績變數, 零組件缺貨

今年度業績有什麼變數? 產能是否已滿, 還是若產能再提前可再上修?

目前營收規模由公司的供給節奏決定. 上行風險是擴產比預期更確實地達成. 下行風險是平常就會發生的部材未依約交貨. 只要缺一項, tester就無法組裝, 影響大時會產出低於計畫.

今年度零組件與原物料是否大致已確保? 2H數字是以大致不用擔心的水準編列. 但若有急劇變化, 下修風險不是零.

零組件與原物料採購上有開始擔心的零件嗎?

仍有部分短交期部材要採購, 很難說100%沒問題. 一般而言, 採購上最擔心的是記憶體半導體, PCB基板及玻璃相關材料等, 這些大多和data center投資搶料. 半導體廠商同時是tester供應商的客戶, 比較好談. 其他部材供應商未必是公司客戶, 談判時較費力.

所以上下行風險都在供給面, SoC可能上修, memory則擔心零組件與材料?

不是, memory與SoC相同. 剛才提到的記憶體半導體是指零組件.

2H仍有手機等non-AI需求, 計畫中是否納入該需求放緩使SoC tester需求下降的風險?

即使發生, 也可轉配給等待中的HPC客戶. 即使手機需求減弱也有轉配對象, 這是對2H的看法.

這表示AI半導體需求並未全部滿足? 公司希望盡量滿足客戶要求的交期, 所以在提前擴產. 如果不需要提前就能滿足, 才代表已經滿足. 因此確實有未滿足的部分.

競爭態勢

中國最大DRAM客戶方面, 是否聽到本土供應商出現?

在memory tester領域, 亞洲客戶有在各自區域培育tester供應商的特色, 這些廠商會有一些影響. 但公司tester需求不會一下子消失.

該客戶未來挑戰先進DRAM, 是否反而是機會?

是. 在這類capex時點, 記憶體有多種量測方式, 客戶應會部分使用本土供應商. 但公司tester的需求機會及受惠程度高.

競爭對手也在準備產能, 考量公司供給狀況, 市佔是否仍會上升?

若大幅無法回應客戶需求, 應更視為風險. 若說擴產提速已完全成功, 客戶會生氣, 但公司相當努力. 目前仍有部分客戶感到困擾, 但不至於嚴重到使市佔快速且明顯改變.

CPO

CPO提到$1b TAM, 是指何時?

無法明確說是幾年後, 將來會到約$1b規模. 但SoC tester目前已有約$10-11.5b規模, 未來數年也會持續擴大. 相對而言, 只看CPO, $1b並不算大, 這是當時說明的主旨.

CPO測試程式還沒確立吧?

半年前(今年4月)發表矽光子及CPO量產用tester後, 已交付客戶並正在評估. 原本就說要花1年以上, 試誤找出各test insertion最適合分配哪些測試項目, 才能建立最佳test flow, 目前仍在進行.

fabless是否急於導入CPO, 因為電力不足所以必須導入?

應該是. CPO量產技術不只測試, 組裝生產也成熟並能穩定量產後, 就能維持各種傳輸速度, 即使chiplet本身性能更高也不用擔心電力問題. 這是客戶希望早日實現及採用的技術.

CPO有insertion 1至3, 有時聽說1是Advantest; 2是Teradyne, 3 (聽起來好像是Chroma… 抱歉不太確定). 分配是否已決定? 還是公司可能以V93000平台包辦1至3?

公司打算在客戶想實現的所有環節提供量測方案. 目前討論的insertion是1至4或1至5, 公司會陪同客戶評估到最終決定, 沒有放棄任何工序. 最終在哪個工序做什麼仍在評估, 公司認知是什麼都還沒決定. 客戶也明確要求供應商不得談論這些內容. 至於tester是否為瓶頸, 許多工序需要精密contact技術, 常需要重做contact部分並重新評估. 客戶最終想決定需要的test data及test condition, 公司認為自己在這方面最有知識. 公司與負責device interface的供應商等夥伴合作, 提供例如要得到某種測試數據就需要修改配線等建議, 一起打造方案.

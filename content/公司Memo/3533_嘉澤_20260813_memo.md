2026/08/13 嘉澤 3533 TT【統一國法訪談會議紀要】




初判:

嘉澤 2Q26 獲利表現低於預期，主因低價原物料庫存於 1Q26 消耗完畢，2Q26 起全面反映金、銅及塑膠等成本上漲，原物料占銷貨成本比重由過往 45%–50%升至 65%，使毛利率季減 4.08 個百分點；此外，員工認股費用及匯兌損失亦進一步壓抑單季獲利。 展望後續，原物料成本仍處高檔，3Q26 毛利率預期僅與 2Q26 相當，較明顯改善最快需待 4Q26 底至 1H27 新平台放量後才有機會顯現。考量短期原物料成本壓力尚未解除，因此看法轉為中立，後續營運重新轉強仍需等待 2027 年新平台放量。

一、 公司基本概況與核心競爭實力



- 全球市場地位與排名：嘉澤是一家專門設計與製造連接器及連接線的廠商，服務伺服器、個人電腦、車用、工控及醫療市場。根據 Bishop & Associate 的統計，嘉澤在全球電腦暨週邊連接器廠商中排名全球第四，在不分行業別的全球連接器廠商中排名第十八。

- 業界領先地位與策略夥伴：嘉澤是全球前三大中央處理器插座（CPU Socket）供應商，被許多世界知名廠商選為策略供應商，因而獲得許多與客戶共同開發新一代前瞻產品的機會。

- 創辦與專利實力：公司由董事長朱先生與總經理何先生於 1986 年共同創立。目前在全球擁有超過 4,000 件連接器及連接線專利，且專利數持續增加中，在台灣連接器廠商中專利數量排名第二。

- 一條龍高度製程整合：嘉澤具備 100% 自行設計與製造的能力，製程高度整合。包含產品設計、模治具及自動化檢測設備開發、射出成型、金屬沖壓、電鍍、組裝等，全部一條龍在廠內完成。這使嘉澤具備極高的靈活性來服務客戶，並能快速回應客戶需求。

- 品質與驗證優勢：擁有取得 ISO 17025 認證的信賴性實驗室，能出具行業標準測試報告，亦可依客戶規範進行測試。這能大幅縮短新產品的驗證時間並降低驗證費用，對產品快速上市至關重要。

- 國際品質管理系統認證：已取得 ISO 9001、IATF 16949（車用）、ISO 13485（醫療）、AS 9100（航太）、ISO 14001（環境）、OHSAS 18001、QC 080000 及 ISO 14064 等多項品質系統認證。

- 全球化辦公室與員工規模：於美國（休士頓、奧瑞岡、聖荷西）、德國（斯圖加特）、新加坡及印度（班加羅爾）設有銷售與技術支持據點。目前全球總員工數已達 14,000 人左右。

三、 2Q26 財務波動與營運指標深度剖析

1. 毛利率大幅下滑原因（QoQ 下滑 4.08%）



- 低價原物料消耗完畢：2025 年採購團隊提前進行大筆備料，享有較低成本的銅、金、塑膠庫存。此低價原料至 1Q26 消耗完畢，2Q26 開始全面反映當前高昂的原物料成本。

- 原物料占 COGS 比重大幅增加：金、銅、塑膠這三大核心原物料占銷貨成本（COGS）的比重，過去約占 45% - 50%，在 2Q26 增至 65%，對毛利率造成顯著影響。

- 學習曲線前端成本：部分新產品尚處於生產學習曲線前期，初期良率與效率成本偏高。

- 運費負擔增加：運送到客戶或倉庫之前的運費由嘉澤承擔，且供應商報價也反映了運費上漲，皆算入銷貨成本中。

2. 營業費用激增原因



- 非經常性員工認股費用認列：2Q26 營業費用為 22.48 億元新台幣（QoQ 增加 3.35 億元）。主要因為去年實施庫藏股，並於今年第二季進行發放，因而認列了高達 2.79 億元新台幣的非經常性員工認股費用。

- 常態性費用水準：若扣除上述 2.79 億元的員工認股費用，2Q26 的常態性營業費用約在 19.69 億元（19 億多元）左右。

3. 業外匯兌損失



- 人民幣快速升值：2Q26 因人民幣對美元快速升值，導致公司單季認列了 1.67 億元新台幣的業外匯兌損失。

4. 營運與財務應對策略



- 持穩與逐步改善：預估 2Q26 為毛利率谷底，3Q26 的毛利率在沒有其他外在意外下將與 2Q26 相當，成本已無持續上升壓力。

- 動態新產品定價：針對新一代平台的產品，嘉澤會根據目前的實際高昂原物料價格重新議價與定價，以反映成本波動。

- 學習曲線與良率優化：公司持續進行內部生產效率與良率改善，且新產品將快速提升學習曲線，成本結構將持續得到優化。

- 顯著回升時間點：由於原物料占比太高，毛利率真正要出現顯著改善，預計需等到 4Q26 底至 1H27新平台產品大規模量產放量，且國際油價回穩（降低塑膠粒成本及運費）之後。

- 下半年費用預估：預期下半年的單季 OPEX 將持穩在 19 億至 20 億元新台幣之間。

五、 伺服器技術演進、水冷與新產品亮點

1. 供應鏈缺料壓抑短期出貨



- 主被動元件與記憶體短缺：目前伺服器出貨受到主被動元件、PCB，特別是記憶體缺料影響，ODM 客戶端月平均生產量由 2Q26 的 1.49 KK/Month 壓抑至 7、8 月的 1.32 KK/Month。

- 客戶應對方式：客戶正透過降規（如從 DDR5 轉回 DDR4，或減少記憶體容量）來緩解瓶頸。

- 成品庫存極低：目前中端客戶的成品庫存非常低，只要有產品基本都能出貨，顯示底層需求依然無虞。

2. 液冷快拆接頭（QD）重大突破



- 客戶打入進度：嘉澤在 QD 業務已成功切入 1 家 CSP（雲端服務提供商）及 1 家平台客戶。

- 進入量產與擴產：7 月份起已正式進入量產，且工廠正同步進行產能快速擴張。

- 營收比重預估：7 月 QD 營收占比約 1%，若後續擴產順利，下半年預估可占整體伺服器營收的 2% - 3%。

- 極高單價與獲利貢獻：QD 單價極高，單顆價格約在 10 幾至 20 美元，而每台伺服器節點約需使用 2 至 3 個（相較於一般連接器單價僅幾塊錢新台幣）。雖然其毛利率低於公司平均（對毛利率有稀釋效果），但對營收、稅後淨利與 EPS 絕對值有顯著的正向貢獻。

3. SOCAMM 與 CAMM（SOCAMM）水冷方案



- SOCAMM正式量產：嘉澤的 SOCAMM 產品已正式進入量產，產能利用率高達九成（90%）以上，並成功打入 Nvidia Vera Rubin。

- 水冷流道與 SOCAMM 設計轉變：當伺服器導入水冷板液冷系統時，傳統的直立式 DDR 插槽在設計上較難規劃水冷流道。因此促使客戶端朝向使用平貼式的 CAMM / SOCAMM 插座設計。

4. CPU Socket 針腳數與高速連接器單價提升



- 引腳數持續上升：目前 CPU Socket 的平均腳數約在 6,000 多 pin 左右。隨著新平台 Birch Stream 及 AMD Venice 等起量，平均腳數預期朝 7,000 pin 以上發展。

- 開發萬針插座：嘉澤目前已經在開發 10,000 pin 以上的 Sockets。

- 單價與價值提昇：由於高速訊號完整性要求，產品結構設計變得日益複雜，使生產難度與成本上升，單價與單顆價值將持續顯著提昇。

5. 其他新產品



- 板對板連接器（Board-to-Board）：公司已成功開發出板對板連接器，並於近期的 OCP大會上正式展出。

- NPO / CPO 光電整合進度：NPO產品已經研發完成並做好量產準備，最快預計於 2027 年配合客戶正式放量，2026 年暫無顯著營收貢獻。嘉澤與持股子公司嘉基在 CPO/NPO 客戶開發上各自獨立，嘉基在光學領域擁有獨立的設計與量產能力。

六、 伺服器 CPU 平台轉換進度與市場份額

1. Intel CPU 平台路線與滲透率



- Eagle Stream (E1, Socket 4677)：目前出貨主力，占 Intel 平台比重接近 50%。

- Birch Stream (BR/E2, Socket 7529/4710)：正快速放量中，2Q26 占 Intel 平台比重已達到 40%。預期明年BR與 E2 兩顆產品合計占 Intel 平台比重將順利超過 50% - 60% 甚至 70%。

- Oak Stream (DX, Socket 9324)：支援 DDR5 / PCIe 6.0，目前尚未正式量產。

2. AMD CPU 平台路線與滲透率



- SP5 平台 (Genoa / Bergamo / Turin, Socket 6096)：為目前 AMD 平台出貨主力。

- Venice 平台 (SP7 - Socket 7536, SP8 - Socket 5572)：

  - 2Q26 的滲透率依然偏低，還不到 3%。

  - 預期 4Q26 將開始進入小量出貨與驗證，大量放量預計在明年年初。

  - 明年Venice 平台的滲透率預計將順利突破 30% 甚至來到 40%。

- SIENA & SORANO：為 AMD 針對特定核心數推出的平台。

3. ARM 架構與 GPU Sockets



- ARM 架構插座：嘉澤目前已在與一家 CSP 共同開發其基於 ARM 架構的 CPU Sockets，目前也在與多個客戶進行溝通與推廣。

- GPU Sockets：目前 GPU 本身多不使用 Sockets（多直接打板），但嘉澤已有相關 GPU 插座案子正在進行中。由於尚未進入正式議價與確認採用的階段，量產時程與單價目前無法透露。

4. 嘉澤全球 Sockets 市佔率



- Intel CPU Sockets：主要供應商為三家（嘉澤、TE、FIT），嘉澤目前市占率維持在 35% - 40% 之間。

- AMD CPU Sockets：主要供應商為兩家（嘉澤、Amphenol），嘉澤目前市占率在 45% - 50% 之間。

七、 最新籌資規劃與產能擴增節奏

為了因應未來新產品的大規模放量、擴建產能並充實營運資金，嘉澤已計劃辦理以下籌資活動：



  1. 現金增資：計劃發行普通股，發行上限為 1,300,000 股（1,300 仟股）。

  2. 國內第三次無擔保轉換公司債（CB三）：發行張數上限為 30,000 張（3 萬張），CB 發行的確切金額上限則仍在進一步確認中。



- 產能擴增節奏：嘉澤對於產能擴建採取逐步推進、不一步到位的穩健政策。產能擴建節奏會提前市場（客戶需求）一季的時間準備好，以靈活應對市場的快速波動與需求變化。

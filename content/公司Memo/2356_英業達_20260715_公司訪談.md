# 英業達 (2356) | 公司訪談
> 公司：[[2356 英業達 (Inventec)]]

## 筆電（NB）業務：Q1/Q2出貨平穩、下半年轉保守

- **Q1/Q2 出貨量相當**：兩季筆電出貨量都約 5.4M 台，上半年合計約 10.8M 台（逐字稿原文數字有雜訊，此處依上下文還原）。
  - 客人在第一、二季持續拉貨，主要因關鍵零組件（尤其 memory）分配吃緊，客人提前備貨
    - 下半年客人轉為保守，主因上半年已拉貨透支

- **全年展望優於同業降幅，但仍是 YoY 下修**：公司全年筆電出貨 guidance 仍呈現 YoY high single digit 到 low teens 的下修，但降幅小於整體產業。
  - 得益於商用機種占比較高，享有 Windows 10 replacement cycle 與 AIPC adoption 紅利
    - AIPC penetration 目前已接近 50%
  - 因關鍵零組件漲價墊高 ASP，筆電營收金額有機會優於 2025 全年（儘管出貨量下滑）

## 伺服器業務：動能強勁，全年營收guidance上修至20%+成長

- **Q1/Q2 營收皆優於預期**：Q1 伺服器營收為 47（單位逐字稿未明講），Q2 較 Q1 更好。
  - 部分原因是零組件提前拉貨，但 enterprise 與 data center 需求本身也強勁
  - 全年伺服器 segment guidance：接近或超過 20% 成長，主因 ASP 提升（AI rack、關鍵零組件漲價）與出貨組合上移（L1/整機占比提升）

- **美系 data center 客戶動能最強**：今年成長爆發力集中在美系客戶。
  - 除既有 ASIC engagement 外，NVIDIA、AMD 機種也貢獻成長
    - 客人在 Q1 季底上修了 General Server（CPU server）guidance，原本僅看好 ASIC/AI，後續也調高一般伺服器展望
  - 中系客戶（如 TikTok、Oracle 帶進來的訂單）雖出貨佔比較小，但多為整機 REG/L1 出貨，單價高、營收貢獻大於出貨占比

- **AI 平台出貨時程**：
  - NVIDIA Rubin：mass production 落在今年 Q4；今年 HGX/VR 架構出貨量偏少，主要機會在明年
  - AMD MI450：Schedule 同樣落在 Q4；single-tray 客戶先出貨，dual-tray（雙袋）預計 rolling 到明年 Q1/Q2
  - 下半年因客人季底上修 General Server forecast，備料需要時間，Q3 表現良好、Q4 視料況可望優於 Q3

## 毛利率與營收認列（法人QA重點）

- **實際伺服器營收占比恐遠高於財報揭露**：依 IFRS 認列規則，consignment 或 buy-and-sell 認列方式影響財報營收數字。
  - buy-and-sell 若客人零組件（key parts）占比未超過 90%，可全額認列；超過 90% 則僅能認列價差（淨額）
    - 公司透露：去年、今年 Q1 財報揭露的伺服器營收占比雖未達 50%，但 actual 出口金額（實際業務規模）伺服器早已超過 50%
  - 分析師換算：財報揭露成長約 20%，但 actual 營收成長可能達 30-40% 以上，差異來自認列口徑而非業務本身

- **H20 對中國解禁疑慮**：目前 growth driver 預測中並未計入此項，若成真將是額外增量。
  - 即便解禁，備料時程需要時間，最快也要 Q4 才可能出貨

- **毛利率展望**：Q2 可能是全年低點，下半年隨產品組合改善逐步回升。
  - 下半年筆電占比下滑（因出貨集中在上半年），data center 中 CPU server 的 GPM 不若 AI server 低
    - 加上下半年 ASIC 設備出貨佳，整體是產品組合問題而非結構性轉差
  - L6（board級）毛利率優於 L10/L11（整機，含 memory/CPU 等關鍵零組件），但 consignment 全額認列 vs buy-and-sell 淨額認列，也會拉動財報 GPM 表現不同
  - Bottom line／OPM：Q2 表現預期優於 Q1

- **AMD MI450/MI45 出貨形式**：目前多為 L6（board），出貨給 Semina（原 ZT partner，現為 Semina 子公司），對 Microsoft 屬 indirect business（path 2 給 ZT/Semina）。
  - 明年起有直接（direct）GPU 相關 project（FPGA），將以 L11 整機形式出貨，屬 direct business
  - MI450 與 MI45（單袋/雙袋）目前無法拆分明確 breakdown

## AI 伺服器產業趨勢：NVIDIA Rubin 模組化與 DGX Roadmap

- **NVIDIA Rubin 走向模組化供應**：相較 Blackwell 世代（TPU board 為固定制式），Rubin 世代 NVIDIA 提供更多元件選擇，客人可自由組合成 NVL4、NVL8、HGX 搭配 PCIe 等不同架構。
  - 背景：上一代 GB200 在部分 data center 客人接受度不如預期，促使 NVIDIA 這一代更開放給客人客製化選擇
    - 目的是降低單位成本——NVL72 整櫃造價約 70 萬美元（分析師估算），並非所有 inference 需求都需要如此高階機種

- **Inference 將成 2027 年主流**：客人對 per-token 成本高度敏感，推動產業朝更具彈性、低單位成本的機櫃配置發展。

- **DGX Roadmap（客戶自研晶片趨勢）**：NVIDIA 仍主推 VR20（約數百萬美元）／Vera CPU／GB200 DGX 架構，但主要 data center 客戶傾向使用自研 ASIC/CPU，甚至希望將自研 TPU/ASIC 推廣給其他 Tier 2 data center 或 new cloud 客戶。
  - 反映 2027-2028 客戶思維轉變：不僅用於自身 AI 應用，也想對外輸出/推廣自研晶片方案

- **產業新進者動態**：
  - FII（鴻海工業互聯網）目前僅承接 L10 到 L1，尚未跨入 L6
  - Avago（Broadcom）相關 TPU 專案（逐字稿原文為「Virgin Sunfish」，疑為技術代號 ASR 誤植，待查證）預計明年 Q2 或 Q3 放量；目前正處於 transition（前一代專案剛量產），Q3 TPU 進入 transition、Q4 ramp，Q2 已開始出貨

## 產能佈局：美國休士頓與泰國投資

- **休士頓廠區**：本季開始有少量出貨。
  - 驅動因素並非單純成本考量：AI server（NVIDIA/AMD/ASIC project）客戶重視 ODM/EMS 是否具備美國在地生產基地，以符合美國製造要求
    - 另一關鍵是電力/電壓基礎設施——AI server 生產對 power、voltage 要求高
    - 新產線須為液冷（liquid cooling）世代預作準備，需要先期投資（先行資本支出）

- **台灣供應鏈仍占 AI server 約 90%**：因具備完整 desktop/notebook/server 到 AI server 的全產業鏈基礎，加上前述電力/液冷/美國製造等進入門檻，形成台廠集中優勢。

- **泰國佈局**：今明兩年為投資重點之一，主要因應客人 commercial（商用）市場布局。
  - 越南市場過去較集中在 consumer 產品，泰國則是次於中國供應鏈、聚焦 commercial 市場的第二大群聚地
    - PCBA、外觀件（enclosure）、connector 等供應鏈已較早進駐泰國
  - 今明兩年投資重點：泰國與美國休士頓（德州）

## 供應鏈關係

- **客戶**：Google、Amazon — ASIC server 最主要兩大貢獻客戶；Microsoft — 目前多為 indirect business（透過 AMD MI450/45 path 2 給 ZT/Semina），明年起將有 direct GPU 相關 project（FPGA，L11 整機形式）；NVIDIA、AMD — GPU/ASIC 機種主要平台夥伴
- **供應商/合作夥伴**：Semina（原 ZT partner，現為 Semina 子公司）— MI450/MI45 出貨的下游組裝夥伴
- **競爭對手**：FII（鴻海工業互聯網）— 新進入 L10 到 L1 領域，尚未做 L6，被點名為新進競爭者

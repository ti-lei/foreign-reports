# 安菲諾 | 專家會議
> 相關公司：[[鴻海]]、[[聯發科]]、[[智邦]]

> ⚠️ 本檔為語音逐字稿（STT）整理，原始音檔雜訊高、專有名詞多處誤植，部分公司名／數字為依上下文最佳推斷（已標註「疑」）。核心結構性觀察可信，精確數字建議回聽音檔確認。安菲諾 = Amphenol（美股 APH，別名「安培諾」）。

## NVIDIA GB300 / VR200 Rack 架構演進與量產進度

- **GB300 → VR200 全面轉向 cableless／水冷、可插卡式設計**：把原本的 IRIS cable 飛線拉掉，改用立盤（midplane）+ 蓋子（cover）結構。
  - GPU 由 Mount 改成 SXM/插卡式；CPU 亦由 Mount 改為插卡式；一個 mainplane 上接 7 張板子（上下兩層）
    - 「cableless」是指組裝時不需 manifold，並非完全無線——manifold 段仍保留線材

- **GB300 mainplane 首家由 [[鴻海]] build，7 月遇到量產問題**：Power 訊號不足、LGA 上想直接用 Mirrorless 仍有問題，方案須重新釐清。
  - Microsoft 例外：把 midplane 改掉、在 SNN 段接一張 riser card 出去，不需該顆連接器，因此可比別人早量產
    - 其他客戶量產落在 8 月底

- **VR200（R20）全系列僅水冷版本**：因水冷可做得非常薄，客戶多偏好；相較前代氣冷（機身很大）薄度大幅改善。

## Vera Rubin 世代與 China 特規（Pulsar B30A）

- **Vera CPU Rack 報價約 700 萬美元／整櫃**：與 NVIDIA VR Ruby（720）標準版相近。
  - 開始用新 SKU（4×20+2 加 Power），CPU 側塞滿 SOCAMM2（記憶體怪獸，本版不用 HBM）
    - 一個抽屜 8 顆、整櫃約 16 顆（ETL256）；internal particle 代號 Neutrino
    - SOCAMM2 單價約 20~30 美元，供應商看到 Lotus 與 疑「世芯/Soken2」兩家

- **B30 SKU 改水冷、記憶體解綁**：客戶可自選 CPU（HGX 版可搭自購 memory），不再被 Grace CPU 綁 LPDDR。
  - 前代 B30 用 Grace CPU + Mount LPDDR，本代改 SOCAMM2

- **Context Memory / Value Routing（無 GPU host tree）**：Context Memory 為 DRAM/SSD 擴充機，走正常 DDR5；SKU 仍在調整、未 file down。
  - Value Routing 目前 6~7 家在做，近期傳出對 Oracle 有興趣；priority 用 4×20×2

- **Pulsar（Intel 代號，B30A）for China**：一顆 CPU 配 8 顆 GPU，SKU 與 GB30/GB20 完全不同。
  - Cable Card 由 立訊（Luxshare）做 LockShare——把 Amphenol 的 pin 公母對調以避開 License 問題
    - 9 月才會大量；目前兩個月每月僅約 200 台；須搭 Vera 一起排，能見度低

## 安菲諾（Amphenol）產品定位與連接器競爭

- **Cable Cartridge 為安菲諾核心料**：Rubin/Kyber/Brook（LT30，belly-to-belly 一張板上下 16 個 LPU）等機種後段皆掛 4 根 cable cartridge。

- **PogoPin 連接器：NVIDIA + FIT（[[鴻海]]）共同設計**：接在 mixer/probe pin 位置，需彈性壓合設計。
  - 單價約 50 美元；力訊 疑（力銘/立訊）為 second source
    - 安菲諾自推一款 PogoPin 型態連接器，單價約落在 50~58 美元
    - 安菲諾另推真正 48G 的新設計「Century」（非 portable beam style），三種方案都推給 NVIDIA

- **Kyber 架構已 postpone 到 Rubin（飛門）世代**：第一版 4 個 chassis、隔年改雙規（跨 caddy 需 cable cloud 對接）。
  - 衍生的 Tekio（NVL28，兩 rack 相連，3~6 月短命專案）與 takehome 設計已確定 cancel
    - Parallel fabric 全挪到旁邊以做薄，cover 版做到約 0.5 公分

## GB300 vs VR200 需求拉貨與客戶動態

- **GB300 壽命超乎預期**：NVIDIA 5→6 月版本 delta 顯示今年 GB30 大幅加量、明年 GB30 仍持續增加。
  - 原預期 GP 數字逐步下降、Vera 起來；但新版顯示 GP 還會活很久，出乎意料
    - Q4 demand 衝到約 16,000 台（尚未實際出貨）；11~12 月能否做完存疑，部分恐落到明年 1~2 月

- **算力／出貨量指標今年衝到 16.8K**（單位待確認），與內部 MPA 數字有落差。
  - 各家上修幅度不一：Microsoft/Oracle 給長期 forecast、變動小；Amazon 與 XAI 變化最大
    - Amazon Q2 突然大量加單：原交 Anthropic 算力，後自研上線、速度很快（T2→T3 一代）
    - 近期加單主力：XAI（下半年負荷大）、Tesla、SpaceX、Costco、PEGA、Supermicro（Supermicro 已排第二名）

- **客戶行為分層**：Google 最穩定、Meta 次之；CSP（含 Tesla 概念）常在最後一刻才給下季算力需求。
  - Oracle 目前都給 long-term forecast；Microsoft 因部分客戶掉單，採購 slow down、多延到明年
    - Microsoft 最後一次大量出貨在今年 1 月（GB30），中間僅少量 deployment，接下來改 VR

## NVIDIA Switch（Quantum / Spectrum）與 CPO 進度

- **Spectrum 標準版走銅線（NearChip solution），量體遠大於 CPO 版**：市場常把 VR20 全當光（CPO），實際標配是銅。
  - Spectrum 660 為 VR20 標配、6810 為 VR20 option；6810 全年約 10K，量產掛 12 月
    - 一個 RAID 至少需一台 TOR，整個 VR20 超過 10K RAID 很容易；CPO（CPU 版）量少
    - 市場說「10K 以上」多指 Spectrum 標準版；真正 CPO 版沒那麼多

- **Quantum（scale-up switch，放中間）**：今年展示 Juliet（GB30）為 near-chip；VR20 走銅為主，VR30 才有真正 CPO option。
  - 真正 CPU（CPO）版 Quantum 要 2027 年底才出，目前在 [[鴻海]] 打樣
    - Spectrum 680 做 spine（整 rig）、內含 4 張 NVIDIA switch + 上方 AMD API controller，16 個 switch 一個 switch rack

## Hyperscaler 自研 ASIC Roadmap

- **Google TPU（Broadcom 疑「Procon/波抗」代工）**：世代 Sunfish → Zebrafish → Whalefish → Icefish → Miroki。
  - Sunfish（v8i/B8i，inference，高客製化）：明年賣算力給客戶都用 v8i，數量不少；Zebrafish（v8ii）明年自用主力，仍走舊雙開門設計
    - Whalefish（≈Sunfish×2，die 堆疊 coax）初期約 50K；Marvell TIA 做 voice-over、memory 走 CXL（舊 CPU memory 打成 CXL 給新 fish 用）
    - Miroki 為 infrared 用、CPC 架構，疑對應昨天提到的「FrozenBit 2.0」；Icefish 開發較早、CPC，最終想做到 64 thread（一 thread 兩顆 GPU=128 格/rack）

- **AWS Trainium（Axiom）**：Axiom 2 搭兩張 BIT-C 板，疑「G5C/世芯系」代工。
  - 今年數量 2 名以內，明年約 1:2（半倍成長）；系統廠對應 Celestia + 疑「世芯」

- **Meta MTIA**：三台架構 Minerva / Santa Barbara / Santa Cruz，Santa Barbara 上三顆晶片（Iris / Arcade / Arcstream）。
  - 首度自研 ARM CPU 兩版：ThinX（用於 YV5）、Venus（用於 Santa Cruz），明年更積極
    - IceCube switch 近一個月出貨破 1 萬（可搭 VR20 或 Santa Barbara）；ICEFALCON 1.6T 用 Broadcom Tomahawk 6，已開第二版、今年打 3 個
    - RAP 從 4K 上修到 20K（每顆約 72 piece）

- **Microsoft Maya**：Maya30 實際約 380K（低於市場傳言）；Maya40 規劃中，原想走 CPU 版恐取消。

- **OpenAI**：三款晶片皆與 Broadcom 合作，明年新一款 foundry 由台積電擴增至含三星。
  - 第一顆今年少量出貨，量集中在明年、約 80K

- **AMD Switch**：兩種（Meta 的 Anacapa、標準版 Polaris）現已合併，最終照 Meta 量產版走。

## CPO / XPO 與 Broadcom Tomahawk / Jericho（過渡技術）

- **XPO 為 CPO 過渡方案（MSA 聯盟，Arista OpenXPO）**：前面走銅纜、pluggable、成本低；過渡期長短無人知（2~5 年）。
  - 架構每顆 32 路、共 64 port，總 bandwidth 可到 12.8T；封裝要求較寬鬆、成本大幅降低
    - 已有不少客戶開始尋找此類方案

- **Broadcom Tomahawk 6 已有 3 種 SKU**：Port 數不同 + CPO 版；Tomahawk 7 有三版本，其中 Davison 版 Q4 才量產。
  - CPO 版本確實在 2027 Q1 量產、掛約 10 萬；ICA 插頁（介於銅與 CPO 的折衷）Tomahawk 6/7 都會有
    - Marvell 明年 switch 拆兩家代工（一家做脂肪 疑、一家做 波卡/Broadcom）

## 供應鏈關係

- **客戶**：NVIDIA（GB300/VR200/Vera/Rubin 全系列，安菲諾供 cable cartridge + PogoPin/Century 連接器）；[[鴻海]]（FIT，GB300 mainplane 首家 build、PogoPin 共同設計、Quantum CPO 打樣）；Google/AWS/Meta/Microsoft/OpenAI（自研 ASIC rack 皆用 cable cartridge/connector）

- **上游晶片夥伴（讀出效應）**：Broadcom（波抗/Procon，Google TPU、OpenAI、Meta ICEFALCON switch）；Marvell（Google TIA、明年 switch 拆兩家）；[[聯發科]]（MediaTek，某 ASIC 首度合作、走舊雙開門架構）；[[智邦]]（志邦 疑，水冷比例/switch 討論帶到）

| Level | 類型 | 定義 | 主要內容 |
| :---- | :-- | :-- | :------ |
| L1 | OEM | 純代工組裝 | 客戶提供全部物料與圖面，僅負責組裝 |
| L2 | OEM | 組裝＋基本製程 | 標準 SOP、製程能力，但不參與設計 |
| L3 | OEM | 組裝＋測試 | ICT / FVT / 燒機等功能測試 |
| L4 | OEM | 組裝＋品質 | OQC、基本品質控管與改善 |
| L5 | OEM+ | 製程工程 | DFM / DFA、良率與製程優化 |
| L6 | OEM+ | Turnkey | 依 Spec 進行 BOM 採購與供應鏈管理 |
| L7 | ODM | 局部設計 | PCB Layout、機構調整、Cost Down |
| L8 | ODM | 子系統設計 | Power / RF / 模組級設計 |
| L9 | ODM | Platform ODM | 提供現成平台供客戶客製 |
| L10 | ODM | Joint Design | 與客戶共同定義產品規格 |
| L11 | ODM | Full ODM | 主導 ID / ME / EE 全設計 |
| L12 | ODM | Solution | HW + SW + Service，接近 OBM |

### 附註:
- **L1–L4**：純製造導向（傳統 OEM）
- **L5–L6**：進階 OEM（工程與供應鏈能力）
- **L7–L8**：OEM → ODM 過渡
- **L9–L12**：完整 ODM / 高價值解決方案

| 能力面向   | L1–L4（OEM） | L5–L6（進階 OEM） | L7–L8（ODM 過渡） | L9–L12（ODM）     |
| :----- | :--------- | :------------ | :------------ | :-------------- |
| 產品定義   | 客戶完全定義     | 客戶主導，OEM 提建議  | 客戶＋OEM 共同     | OEM 主導或共同       |
| 設計責任   | 無          | 製程相關          | 局部模組設計        | 全產品設計           |
| 工程參與   | 無          | DFM / DFA     | EE / ME 局部    | ID / ME / EE 全面 |
| BOM 控制 | 客戶         | OEM 代採        | 共同決定          | OEM 主導          |
| IP 擁有  | 客戶         | 客戶            | 客戶 / 共享       | OEM 或共享         |
| 技術門檻   | 低          | 中             | 中高            | 高               |
| 毛利水準   | 低          | 低～中           | 中             | 中～高             |
| 客戶黏著度  | 低          | 中             | 中高            | 高               |
| 可替代性   | 高          | 中             | 低             | 極低              |
| 商業角色   | 代工廠        | 製造夥伴          | 技術夥伴          | 解決方案夥伴          |

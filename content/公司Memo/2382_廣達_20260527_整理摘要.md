# 廣達電腦 (2382) | 公司訪談

## Q1 結果與 Q2 展望

- **Q1 整體**：管理層表示 Q1 result 已於法說會揭露，不另贅述；Q2 每個月維持不錯，尚未有明確衰退信號。

- **Q1 毛利率結構**：YoY 差距細算約 20 bps 來自一次性費用，其餘為產品組合。
  - 總差異中 2/3 為 server 產品組合（AI server 比重提升後加工費佔比被稀釋）
  - 1/3（約 50 bps）為一次性費用；財務長提及其中約三四成 → 一次性約 20 bps
  - 這些一次性費用（良率、建線、測試）已於 Q1 認列，後續不再重演

- **Q2 毛利指引**：未明確給 guidance，但管理層認為有機會改善。
  - 改善來源：no-book（自有品牌）比重回升，AI server 端 H 系列的陡降效果趨緩
  - GB300 佔比提高，但 marginal 影響不如 H 系列斷崖式消失那麼大

- **NB 下半年出貨量**：YoY 衰退雙位數以上，全年亦抓雙位數衰退。
  - 主因：memory 漲價壓制 consumer 升級意願；管理層直說「現在你自己會願意買筆電嗎？」
  - 去年 Q1 有 Win10 EOL 企業換機潮拉抬基期，今年無此順風

## AI 伺服器獲利結構與 YoY 誤讀

- **YoY 被誤讀的核心**：H 系列（HGX）快速燒完 + NB 衰退雙重拖累，掩蓋了 GB200/300 實際的成長。
  - 去年 Q1 H100 供不應求，AI 毛利極高；今年 GB200 單價更高但毛利 % 反而較低
  - 200→300 不只是 AI server 世代換代，還夾帶 H 系列「前代庫存快速消化完」的 mix 效果
  - 去年 Q4 歷史新高後，今年 Q1 仍是次高，管理層認為沒有外界想的那麼差

- **GB200/300 毛利百分比低的結構原因**：機櫃 ASP $600–700 萬美元，加工費佔比被材料成本稀釋。
  - 每臺的毛利金額（absolute dollar）仍在成長，只是 % 數字偏低
  - 管理層舉例：公司從 14 萬人縮到 7 萬人，EPS 反而更高——高 ASP 產品的利潤池更大

- **全年 AI double 目標不變**：以 AI 營收計算（非台數），去年估約 1 兆台幣、今年 target 2 兆台幣。
  - 一個 quarter 均攤約 8,000 億台幣（整體廣達），下半年高檔震盪，非大幅爬坡
  - 下半年 Q3/Q4 有 Vera Rubin 少量出貨貢獻，但大量量產要等明年

## Consignment 模式轉型與資金壓力

- **核心問題**：機櫃 ASP 升至 $600–700 萬美元，廣達備料（Banker/Financer 模式）已難以為繼。
  - 廣達股本約 800 億台幣，若做 4–5 千億以上生意需大量借款，負債比過高影響信評
  - 整條供應鏈都缺錢：CSP 客戶自身 Capex 累計超過 $7,000 億美元，也要大量資金

- **目標：轉向 Consignment（客戶自帶晶片）**，下半年開始 case by case 與 CSP 談。
  - 談法因客戶、project 屬性而異：memory 拿掉、或 GPU+memory 全部 consignment
  - NV GPU 是最關鍵節點（最貴、量最大），解決這塊等於解決大部分壓力
  - 廣達需主動說服客戶，因為 CSP 自己也有龐大 Capex 壓力，不會輕易答應

- **Consignment 對毛利率的影響**：短期失去利息/倉儲收入，但毛利百分比預期反而改善。
  - 去掉最貴的材料後，加工費佔比回升，% 數字更好看
  - 管理層補充：就算是 consignment，廣達還是一分加工費都不少

- **GDR 發行**：最高上限 245 million shares，稀釋約近 6%，部分目的為強化資本基礎。
  - 過去融資管道：直接借款、ECB（已兩次），現在以廣達營收規模需要更大股本支撐

## 產能擴張計畫

- **全年 AI server 產能目標**：2026 年底比 2025 年底翻倍，已看到 2027 年訂單作為投資依據。
  - 管理層：「沒有看到訂單我不會去投，客戶給我信心（visibility）我才跟著投」

- **台灣**：桃園廠電力已飽和（「桃園沒有電了」，土地也難取得），以後段製程為主。

- **泰國（SNT 廠）**：2019 年設立，現已擴大 4–5 倍，承接前段製程（L6 SNT），AI server 持續擴產。

- **美國（加州 + 田納西）**：超過 20 棟建築，約 3,000 人，貼近 CSP 客戶機房。
  - 主要挑戰：拉電需 1 年多、州政府許可、土地取得
  - 管理層反駁「美國人力貴」論點：AI server 製程中，人力已非主要成本，利潤池夠大

## Vera Rubin 與產品世代轉換

- **Vera Rubin 時程**：Q3 預計有 sample，Q4 可能少量出貨，大量量產要到 2027 年。
  - 機櫃 ASP 估計更高於 GB300（$600–700 萬美元），複雜度再上一層
  - Thermal 問題（Fermi issue 傳聞）仍是整條供應鏈集體要解決的工程挑戰

- **GB300 現況**：GB200→300 架構相近，學習曲線有延續，但 300 更燙更複雜。
  - 目前出貨量爬坡曲線尚未明朗，Q3 底有 sample 但量產節點不確定
  - 管理層認為 GB300 本身獲利不差，只是比去年 H 系列大好的時候顯得遜色

- **三大廠格局**：廣達 / 緯創 / 其他，管理層認為比例不會大幅變動。
  - 機櫃越來越貴（$600–700 萬），客戶不敢隨便找缺乏驗證的廠商做
  - Open AC（AMD / SK Hynix 體系）：case by case，單價低於 NV 體系

## NB 業務前景與轉型難度

- **NB 現況**：仍在賺錢，不到手錶業務（長期虧損才退出）的程度，但獲利薄且承壓。
  - 聯想曾提出 joint 入股 49% 做 NB，廣達未接受
  - 主要壓力：Consumer 持續疲弱、memory 漲價、企業換機潮基期效應消退

- **轉型至 AI server 的難度**：NB 的 BU 人力組與 AI server 技能組不同，redeployment 有學習曲線。
  - AI server BU 本身也很缺人，不是「NB 沒生意就轉過去做 AI」那麼簡單

- **Consumer PC 出貨量長期結構性壓縮**：單月出貨曾達 750 萬台，疫情後跌至 100 萬台，目前在低檔。

## 供應鏈關係

- **客戶**：CSP hyperscalers（未具名）— AI server 主要客戶，合作超過 20 年；GPU / memory 由客戶直接與上游廠談價格和量，廣達負責組裝
- **供應商**：NVIDIA — GPU 最主要供應商，機櫃最大成本來源，consignment 轉型的關鍵節點；客戶直接與 NV 談量和價
- **供應商**：Micron（美光）— memory 供應商，客戶直接談
- **競爭對手**：緯創 — 三大 AI server ODM 之一，市占格局相對穩定

## PQ 拆解

### AI Server 業務
- **Q（量）**：今年 AI 營收 target YoY double；去年估約 1 兆台幣 → 今年 2 兆台幣；台數成長比例小於營收成長（ASP 拉高效果）

### NB 業務
- **Q（量）**：下半年 YoY 出貨量衰退雙位數以上；全年抓雙位數衰退

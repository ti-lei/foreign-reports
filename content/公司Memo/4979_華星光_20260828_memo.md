# 4979_華星光 | 2026-08-28

> 來源：LINE memo（2026-08-28 分享）

🔴華星光(4979)法說會memo中信投顧 20260828

財務概況：

1. 營收12.9億元。
2. 毛利率22.5%，季減主因財稅認列時點差異，3Q會認列。
3. 稅率以20%估算，6月有未分配盈餘加計10%所得稅，因此2Q26稅率較高。
4. EPS 1.29元。

營運概況：

1. Lightcounting三度上修資料中心CPO/NPO/TRX需求，2031年由520億上修至800億美元。
2. AI伺服器需求帶動資料中心內光模組需求，2026年需求800G 7,000萬(去年預估3,500萬)、1.6T 1,500萬，2027年1.6T 6,000萬。模組往單模、高速、高功率、多波發展。
3. 光源來看2026年CW模組8,500支，對應4億顆CW需求，EML模組1,800~2,000萬支，對應1.6億顆EML需求。CW會成為主流，EML會持續留在高性能、高功率、長距離、單模的應用。
4. 2027~2029 NPO取代CPO成為主流，主因CPO良率問題、無法維修，預期2030年CPO才會成為市場主流。
5. DCI方面2026年400ZR仍是主流，800G會開始有一點，明年兩者加起來200萬支，2031年達到300萬支。400G持平往下，800G會有顯著成長，27/28/29年100/130/150萬支。
6. 市場份額領導者：400G 新易盛，800G中際旭創，ZR Marvell。

產能：

1. 2024年：無塵室4,000 m2。
2. 2025年：1Q合江廠新增950 m2，3Q吉林廠新增1,500 m2。
3. 2026年：竹東1,200 m2 3Q投產，辦公室500 m2。
4. 2027年：5月購買八德廠5,500 m2，明年底建置完，無塵室空間可達13,000 m2。
5. 2028年：大概還有額外10,000 m2。
6. 合江廠：整棟變成InP晶片工廠，月產能3,000片，2028年會有4/6吋的自動化生產線建置，整棟建築約5,000 m2做InP晶片。
7. 八德廠：DCI模組組裝、測試。
8. 吉林場：封裝基地，包含NPO。
9. 總產能：wafer fab今年3,000片，明年6,000片年產能。die fab今年3,000萬。
10. 總產出：2025年wafer 3,000片，1,400萬顆晶片。2026年wafer 6,000片，3,000萬顆晶片。2Q26開始chip用在1.6T比較多。

技術發展：

1. Wafer今年會做到4吋，產品往更高功率、更多波長發展，CW目前已做到16個波長，市場大多做單波、4波，因此公司市占率高，多波公司是全球產出最多，毛利也會比較好。EML、高增益APD下半年投入量產。
2. 封裝CoC、CoB以外有開發NPO，2028年會有明顯業績貢獻，模塊持續生產、研發、擴產。
3. 目前產品2吋：20/40/70/100 mW CW、100G EML。3吋：2025年開始發展，70/100mW CW、100/200G EML，之後會有400mW(DFB+SOA)。2028年後會往4、6吋發展。
4. EML：Epi wafer來自誼虹，團隊來自於Source，公司負責EML製程，2H投入量產，2027年會有較大量生產，持續擴充產能。
5. 模組封裝：800G今年批量生產，明年需求比預期多，訂單沒問題主要還是供貨問題。1.6T NPO封裝開發中，與台灣、日本廠商開發設備，2Q27完成開發，2H28進入量產，2028年後量很大，後續會往3.2T NPO發展。2030年會延續至CPO。
6. 製程：可做到0.3um die bonding。今年會發展Flip chip。另外有NPO的Fiber/Lens array attachment。FAU/Lens主動對準精度<0.1um。

Q&A：

1. 客戶集中度：模組+封裝占比85%，InP 15%。DCI集中於兩家品牌，公司維持單一客戶獨家供應。InP今年會增加客戶，增加產品總類、降低風險。
2. 產能：2026年成長一倍，2027年成長一倍以上。
3. 2H26營運展望：DCI新產品，CW、EML、DCI既有產品也有成長，2H相比1H大幅成長。
4. 2027年營運展望：會延續2026成長，新產品在營收上會有跳躍性成長，能見度可看到2028年。
5. 美禁中光模組影響：2024年非紅開始公司就有得到紅利。
6. DCI產品：2027年新DCI會跟既有DCI營收相當，亦即2027年DCI產品營收有一倍以上增長，2028年新產品也會比既有產品多出數倍。下一代DCI產品已在研發，2027/2028會有小量出現。
7. 資本支出：2026年有比預期高，實際支出18~20億，包含InP、模塊，主要在無塵室、廠房、設備投入，攤提年限長，2027年保守估計30億台幣，2028年也會興建土建。公司InP產品都有客戶consign設備支持，降低風險。
8. 雷射後段產能規劃：持續增加，2027年擴增一倍以上，EML、CW同時增長。產能2026年底600萬/月，2027年底1,200萬/月。2027年2~4吋都有，取決於客戶需求及基板狀況，4吋設備4Q27會開始出來。

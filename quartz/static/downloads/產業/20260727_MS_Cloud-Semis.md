## 報告總結

Intel 2Q26 法說釋出對 x86 伺服器 CPU 的強勁需求訊號，MS 認為對其覆蓋的大中華雲端半導體標的（信驊 Aspeed、瀾起 Montage）為正面 read-across。Intel 資料中心與 AI（DCAI）需求跨雲端/企業加速，客戶日益認知 x86 CPU 在 AI 基礎設施的關鍵角色，2Q 再獲策略客戶與長約，當前挑戰是擴充供給以滿足需求；Intel 自研 ASIC 業務目前 US\$2bn run rate、預期近期升至 US\$4bn。客戶持續釋出強勁且可持續的支出訊號，惟晶圓/記憶體/基板供給全面吃緊；Intel 上修伺服器 CPU 展望，預期全球伺服器 CPU 產業今明兩年強勁雙位數成長並延伸至 2028。

投資含意：伺服器 CPU 需求上行直接利多信驊（伺服器 BMC）與瀾起（記憶體介面/PCIe 互連）等雲端半導體 IC，維持兩者 OW。

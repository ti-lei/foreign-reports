# Daiwa｜Taiwan Testing Interface — 8 月三廠同創新高，Semicon 後詢問度大增

## 報告總結

Semicon Taiwan 後，投資人詢問半導體測試介面供應鏈的頻率明顯上升。Daiwa 覆蓋的三家台灣測試介面廠——穎崴（6515）、旺矽（6223）、中華精測（6510）——8 月全數創月營收新高，均由 AI/HPC 需求驅動。穎崴 2H26 產能擴張超前預期；旺矽 CPO insertion 3 設備 4Q26 開始出貨，1H27 進入量產；中華精測正競逐三個 AI/HPC 探針卡整包計畫（含 CPU ASIC、汽車 AI ASIC、台系 AI ASIC），成功資格認證將成 2027 年業績重大上修催化劑。

## 個股摘要

### 穎崴科技 (WinWay, 6515 TT)
**評等** Buy (1)　**TP** TWD\$10,000（70x 4Q forward EPS）

**8 月月營收** TWD1.71bn（+6.6% MoM / +233.4% YoY）；1-8M 累計 TWD9.81bn（+97.9% YoY）；Jul-Aug 達 3Q26E 的 72%，超前預期。

成長主力：北美 GPU 大廠與雲端超大規模客戶 tape-out 持續放量，專有同軸測試座及進階晶圓級垂直探針卡出貨大增。管理層確認 2Q26 為近期低點，後續 QoQ 順序成長。供應鏈核查顯示產能擴充執行進度超前，2027 年新增產能啟動時機請關注 11 月中的 2H26 法說。CPO 座/探針卡貢獻：Daiwa 估 2027E mid-single digit、2028E high-single digit（市場或高估速度）。

---

### 旺矽科技 (MPI, 6223 TT)
**評等** Buy (1)　**TP** TWD\$8,415（65x 4Q forward EPS）

**8 月月營收** TWD2.05bn（+13.4% MoM / +69.9% YoY）**首次突破 TWD2bn**；1-8M 累計逾 TWD13.0bn。Jul-Aug = 3Q26E 的 63%，略低於預期。

VPC 及 MEMS 探針卡在 HPC/AI 加速器/高速網路 IC 量產爬坡中接近全產能。AST 熱測試設備對歐美汽車及 R&D 實驗室持續出貨。雖 3Q26 指引保守引發疑慮，Daiwa 認為 9 月集中出貨 + 高階 VPC/MEMS 新定價啟動應能補齊缺口。**CPO insertion 3 設備 4Q26 出貨，1H27 量產訂單**→多年成長跑道確立。

---

### 中華精測 (CHPT, 6510 TT)
**評等** Buy (1)　**TP** TWD\$4,000（45x 4Q forward EPS）

**8 月月營收** TWD638m（+3.9% MoM / +54.3% YoY）；1-8M 累計 TWD4.25bn（+33.1%）；Jul-Aug = 3Q26E 的 66%，in-line。8 月單月 EPS TWD5.29（淨利 TWD174m，+95% YoY），季度化 EPS 隱含 TWD15.87（vs. Daiwa TWD16.08 / 市場共識 TWD17.52）。

**三大 AI/HPC 整包計畫競標中**：
1. CPU ASIC 計畫（進展中）
2. 美系車廠 AI ASIC — 11 月出工程探針卡驗證，年底前出結果
3. 台系 AI ASIC — 進行中

成功資格認證 = 比單賣測試板更高的 content value，2026 年底提供增量收入，並成為 2027 業績重大上修的催化劑。

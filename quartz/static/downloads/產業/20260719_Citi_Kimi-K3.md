## 報告總結

Moonshot AI（中國）於 2026-07-18 發布 Kimi K3，2.8T 參數、目前全球最大開源（open-weight）LLM，架構創新（KDA+AttnRes+Stable LatentMoE）使訓練效率比 K2 提升 2.5x，推理成本僅 US\$0.3/M cache-hit 輸入代幣、US\$15/M 輸出代幣，顯著低於封閉前沿模型。Citi 認為此次發布將觸發「Jevons' Paradox」效應：模型推理成本下降 → AI 使用量爆增 → 每次推理 KV cache 記憶體需求上升 + AI Agent 增殖帶動更多 token 生成 → 伺服器 DDR5 和 eSSD 需求增加，維持對記憶體板塊建設性觀點。

此報告為純文字 Flash（9 頁，無圖表），催化劑為 Kimi K3 發布後的快速市場解讀。

## 關鍵技術補充

**Kimi K3 架構三大創新：**
1. **Kimi Delta Attention (KDA)**：混合線性注意力機制，使 100 萬 token 上下文視窗可在合理成本下運行
2. **Attention Residuals (AttnRes)**：跨模型深度選擇性檢索表示，強化長序列推理能力
3. **Stable LatentMoE**：極端 MoE 稀疏（896 個專家，每 token 激活 16 個），實現高效計算

**記憶體需求推導：**
- KV cache 需求隨 token 生成量增加而線性擴大（長上下文窗口 1M tokens 尤甚）
- Kimi K3 定位為 long-horizon agentic work → AI agent 持續生成 token → eSSD 快速存取 KV cache 的需求同步上升
- 開源模型廣泛部署後，推理伺服器規模將遠超訓練時期

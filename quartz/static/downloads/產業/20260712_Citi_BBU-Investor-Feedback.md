## 報告總結

本報告為 Citi 繼 Dynapack 啟動覆蓋與 BBU 行業報告後，彙整機構投資人的主要問題與 Citi 立場。整體投資人反饋正面，認為 BBU 主題（AI 機架電源密度提升、rack-level 備援電源滲透率上升）具吸引力，Dynapack (3211.TWO) 是切入 BBU 週期的主要標的。Citi 澄清：HVDC 延遲不影響近期論點；PSU 供應商垂直整合 BBU 的機率低；台灣廠商 vs Panasonic 的份額仍有大幅擴張空間。

## Citi 完整投資邏輯鏈

| 論點層次 | 內容 |
|---|---|
| 近期需求驅動 | AI 機架功率密度上升推動 3kW/5kW BBU 持續成長，8kW/12kW BBU 預計 4Q26E 開始量產 |
| HVDC 風險緩解 | HVDC 25kW 模組為長期增量，不是近期成長必要條件；驗證 1H27E，量產 2H28E，不影響 2026-27 預估 |
| 競爭壁壘 | BBU 需要電池組設計、BMS 整合、熱管理、安全認證，PSU 供應商難垂直整合；Citi 認為 PSU 廠更傾向外包 |
| 份額空間 | AES 與 Dynapack 各 <10% 市占，Panasonic 主導但 CSP 傾向多元化供應鏈；台灣廠份額擴張路徑清晰 |
| Dynapack 股價催化劑 | 1H26 跑輸係因 BBU <50% 銷售額、被傳統 IT 業務稀釋；2H26E 起 BBU 貢獻增加，盈利拐點重新受關注 |
| **結論** | **BBU 近期論點穩固（3kW/5kW＋8kW/12kW 4Q26E）；Dynapack 2H26E 盈利加速為主催化劑；TP NT\$800 維持** |

## 報告核心觀點（5 大 Q&A）

| 問題 | Citi 立場 |
|---|---|
| HVDC 延遲是否衝擊論點？ | 不影響近期；HVDC 是長期增量驅動，近期看 3kW/5kW 持續 ramp＋8kW/12kW 4Q26E |
| Dynapack HVDC 產品時程？ | 25kW 模組：驗證 1H27E，小批出貨 2H27E，有意義貢獻 2H28E |
| PSU 廠商會自製 BBU 嗎？ | 不太可能——BBU 需完全不同的技術（BMS、熱管理、安全認證），PSU 廠傾向外包 |
| 台廠能搶 Panasonic 份額嗎？ | 能——CSP 傾向多元化採購，AES/Dynapack 各 <10% 市占，空間大；Dynapack PSU 合作模式提供進入 CSP 平台的捷徑 |
| Dynapack 為何 1H26 跑輸？ | BBU <50% 銷售額 → 被傳統 IT 業務（y/y 下滑）稀釋；板塊輪動也是因素；2H26E BBU 貢獻增加後盈利拐點重現 |

## 報告總結

本報告是 Bernstein 「New Memory LTAs」系列的第二篇，針對投資人對第一篇的問題與反饋，以歷史半導體 LTA 案例研究（Microchip PSP、Hemlock Polysilicon）做更深入的對比分析。核心論點：**New Memory LTAs（SNDK / MU）具備三大結構差異**，使其比過去任何 LTA 都更具法律效力與商業可持續性——①前置財務擔保（後端加權，外年覆蓋率達 75-100%）、②更優質的對手方（投資評等超大型業者 vs 破產邊緣的太陽能廠商）、③結構性需求（AI 驅動的長期建置 vs 週期性 COVID 搶貨後遺症）。

Bernstein 結論：New Memory LTAs 提供「有意義但非無限」的下行保護。Sandisk 以 >US\$11bn 擔保支撐約 US\$69bn 剩餘履約義務；Micron 持有 US\$18bn 現金保證金 + US\$4bn 信用狀。即使 NAND 未來大跌，超大型業者因 AI 基礎建設是戰略必需品，違約的代價遠大於履約的成本。

## Exhibit 1｜Old LTAs vs New Memory LTAs：這次真的不同

*(文字比較表，非圖片)*

### 解讀摘要

三個維度比較 Microchip PSP（類比/MCU）、Hemlock Polysilicon（太陽能多晶矽）和 New Memory LTAs（SNDK/MU）。關鍵差異在於：(a) 需求驅動因素從「存貨周期拉貨」變為「AI 結構性建置」；(b) 對手方從破產邊緣的太陽能廠商變為財務穩健的超大型業者；(c) 合約條款從「僅憑訴訟」變為「預先持有擔保」。

### 表格

| 維度 | Microchip PSP | Hemlock Polysilicon | New Memory LTAs（SNDK/MU） |
|---|---|---|---|
| 產業結構 | 分散；數十家可替換的類比/MCU 廠商 | 中度集中（少數全球製造商） | 寡頭壟斷（約 3 家 DRAM / 6 家 NAND） |
| 需求成長輪廓 | 短缺驅動 + 重複下單 → 客戶超量存貨後反轉 | 政策/補貼驅動太陽能榮枯；2008 後過供 | 結構性 AI/資料中心建置；高端記憶體供應售罄至 2026-27，雙方規劃延伸至 2027-30 |
| 客戶集中度 | 極度分散（龐大客戶基礎） | 小型太陽能模組廠商，部分後來破產 | 集中於少數高品質超大型業者/AI 買家 |
| 客戶類型 / 資產負債表 | 混合工業/汽車 OEM 和分銷商；信用品質不一 | 薄利、依賴補貼的太陽能商；SolarWorld AG 最終破產 | 資金充裕的超大型業者，可提供 US\$10-20bn+ 現金和信用狀 |
| 履約誘因 | 最終需求放緩；持有過量存貨成本高於違約，誘因弱 | 需按高於市場的原料合約價格，同業可買更便宜現貨，強烈誘因違約 | AI 基礎設施是業務關鍵，記憶體掌管萬億美元機會；保證金相對履約成本微不足道，強烈誘因履約 |
| 合約條款 / 可執行性 | 12 個月滾動 NCNR，無現金；2023 年 8 月鬆弛至 6 個月，2024 年 2 月停止新訂單；僅靠聲譽，未強制執行 | 固定價格 take-or-pay；只能訴訟，即使勝訴 ~US\$793mn 也因客戶破產幾乎無法收回 | 多年量/價承諾，以現金保證金、信用狀或第三方擔保支撐，覆蓋比例在後段合約期升至 75-100% RPO |

> **洞察一**：Microchip PSP 常被引用，但它既沒有現金擔保，需求也是一次性存貨泡沫——與 New Memory LTAs 的結構相似度極低。最接近的歷史案例是 Hemlock，但 Hemlock 的問題在於「勝訴但無法收款」，而 New Memory LTAs 的前置擔保解決了這個核心問題。

## Exhibit 2｜紙面索賠 vs 真實保護

*(文字比較表，非圖片)*

### 解讀摘要

Hemlock take-or-pay 依賴訴訟，過程漫長且最終因對手破產而回收空洞。New Memory LTAs 的擔保「預先在供應商或受信任第三方手上」，客戶破產也不影響保護效力。最關鍵的「後端加權」設計使保護在合約最後幾年（最高風險期）最強，覆蓋率升至 75-100%。

### 表格

| 維度 | Hemlock Take-or-Pay | New Memory LTAs（SNDK/MU） |
|---|---|---|
| 簽署時的財務擔保 | 無顯著後端加權財務擔保；只有分期預付款記入未來採購 | 簽署即存入現金保證金 / 信用狀 / 第三方擔保；合約後端才返還 |
| 保護性質 | 法律索賠；供應商需訴訟才能收款 | 財務擔保已由供應商（或供應商可取得的第三方）持有 |
| 客戶違約的補救措施 | 提起訴訟，訴訟多年後再嘗試收款 | 直接動用財務擔保 |
| 時間上的保護性質 | 靜態；合約條款不隨時間加強 | 動態；擔保覆蓋率隨剩餘義務縮減而上升 |
| 外年強度 | 弱——Hemlock 只有預付款，無後端加權財務擔保 | 最強——後端返還設計使覆蓋率在外年升至 75-100% RPO |
| 客戶陷入財困時的結果 | 判決往往無法執行（SolarWorld AG 破產，Hemlock 即使勝訴也回收有限） | 財務擔保已在供應商或受信第三方手上，客戶破產不消除保護 |
| **最終結果** | **勝訴卻幾乎沒有實際經濟回收** | **結構性加強的保護，在週期下行時精確保護利潤和盈餘** |

> **洞察一**：SNDK 以 US\$11bn+ 擔保支撐 ~US\$69bn 剩餘義務（~16% 即時覆蓋率），但後端加權設計使外年覆蓋率大幅升高。MU 的 US\$18bn 現金保證金 + US\$4bn 信用狀 = US\$22bn，相對其客戶規模，是目前揭露中最具體的數字。

## Exhibit 3｜New Memory LTAs：更優質的對手方風險輪廓

*(文字比較表，非圖片)*

### 解讀摘要

超大型業者（Google、Amazon、Meta、Microsoft 等）的收入高度分散，記憶體成本在整體盈餘中佔比極小，不存在「因記憶體漲價而威脅企業存亡」的情況——與多晶矽佔太陽能模組 BOM 75% 的情況截然不同。超大型業者僅為少數幾家且擁有投資評等信用，可收回性遠優於分散且薄利的太陽能廠商。

### 表格

| 維度 | Hemlock（例如 Sachsen 客戶） | New Memory LTAs（例如超大型業者） |
|---|---|---|
| 客戶類型 | 太陽能晶圓和模組製造商 | 超大型業者、大型 OEM 和 AI 基礎設施提供商 |
| 客戶收入結構 | 幾乎完全依賴太陽能產業鏈；多晶矽是單一主要成本暴露 | 分散於雲端基礎設施、廣告、軟體和企業服務；記憶體是眾多投入之一 |
| 履約對客戶的影響 | Take-or-pay 價格偏離崩潰的現貨市場，大到摧毀利潤和企業本身 | 記憶體成本佔整體盈餘比例極小，吸收後不影響核心業務存亡 |
| 客戶數量 | 眾多分散的太陽能製造商 | 少數超大型業者 |
| 客戶財務強度 | 多家資本薄弱，頻繁承受財務壓力 | 投資評等資產負債表，透明的資本規劃 |
| 出現短缺時的可收回性 | 依賴財務承壓客戶群的清償能力，即使勝訴也難以收回 | 可問責且可靠；超出擔保以外的短缺可實際收回 |

## Exhibit 4｜類比 vs 記憶體需求：物理限制 vs 指數型 AI 擴張

*(文字比較表，非圖片)*

### 解讀摘要

類比晶片和 MCU 需求是「氧氣型」——一台車只需要固定數量的晶片，庫存滿了就沒有追加需求。記憶體需求是「指數型」——每多一 GB 記憶體都讓 AI 模型更聰明（更大的上下文視窗、更多參數、更多並發推理），需求不會因「夠用了」而停止成長。Microchip PSP 的非可撤銷訂單在需求觸頂時崩解，而 AI 記憶體的需求天花板尚不可見。

### 表格

| 維度 | 類比 / MCU 晶片 | 記憶體晶片（DRAM/NAND/HBM） |
|---|---|---|
| 需求本質 | 必要但有限——如氧氣，夠了就不需要更多 | AI 能力的基礎——更多記憶體直接讓 AI 更聰明 |
| 規模化行為 | 需求有上限；固定分配給單位生產（汽車、家電、工業設備） | 隨 AI 工作量成長持續擴展——更大的模型、更多推理、更多資料中心 |
| 短缺期的需求驅動因素 | 主要是提前拉貨：客戶為應對 COVID 供應危機超量下單，而非真實消費增加 | 結構性建置：由 AI 訓練和推理工作量的真實複利成長驅動 |
| 基礎經濟邏輯 | 固定配額，填滿即可，之後不再需要 | 持續擴張的資源需求，與 AI 能力成長掛鉤 |
| 對 LTA 可信度的影響 | 「不可撤銷」訂單在提前拉貨反轉後實際上無法執行 | 以真實擔保支持的長期承諾是可信的，因為底層消費是持久且戰略上不可替代的 |

> **洞察一**：「記憶體是指數型需求」這個論斷是 Bernstein 整個 New Memory LTA 多頭框架的核心假設。若 AI 訓練/推理工作量出現明顯天花板（如 NVIDIA scaling 遭遇瓶頸），此假設就會動搖，是本報告最大的下行情境依據。
